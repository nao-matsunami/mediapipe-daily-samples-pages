Pose Landmarker で姿勢バランスを読む

Read posture balance with Pose Landmarker

MediaPipe Tasks Vision Pose Landmarker の 33 点ランドマークを使い、肩・腰・足首の左右差から簡易バランス指標を出す自作 HTML ラボを追加しました。アップロード画像、カメラのフリーズフレーム、合成ポーズの fallback で動きます。

一覧代表サンプルを開く

今日の重要トピック

  1. Pose Landmarker は人体の 33 点ランドマークを返し、姿勢解析、動作分類、フィットネス UI の最小入力として扱いやすい。

    Pose Landmarker returns 33 body landmarks, making it a compact input for posture analysis, motion classification, and fitness UI.

  2. Web 版は `@mediapipe/tasks-vision` と `FilesetResolver.forVisionTasks()` で WASM とモデルを読み込み、静止画では `detect()` を実行する。

    The Web version loads WASM and the model through `@mediapipe/tasks-vision` and `FilesetResolver.forVisionTasks()`, then runs `detect()` for still images.

  3. 公式ガイドでは `detect()` と `detectForVideo()` が同期実行で UI thread を塞ぐ点が示されており、ライブ化するなら Worker 化が次の課題になる。

    The official guide notes that `detect()` and `detectForVideo()` are synchronous and block the UI thread, so Worker execution is the next step for live use.

  4. Pose Landmarker の normalized landmarks は Canvas overlay と相性がよく、肩・腰・足首など少数の点だけでも独自のスコアやフィードバックを作れる。

    Pose Landmarker normalized landmarks pair well with Canvas overlays; a few points such as shoulders, hips, and ankles are enough for custom scoring.

  5. 今日の公開代表は外部デモではなく、このワークスペース内の `Pose Landmarker Balance Meter` という自作サンプルにした。

    Today's public representative is the original `Pose Landmarker Balance Meter` sample in this workspace, not an external demo.

注目事例と何が面白いか

Notable example and why it matters

今日の注目は Pose Landmarker を単なる骨格表示ではなく、少数のランドマークから UI 向けの指標へ変換することです。公式概要では姿勢解析や動作分類に使えるタスクとして説明されており、33 点の normalized landmarks と world landmarks が得られます。今日のサンプルでは shoulder、hip、ankle の左右差を簡易スコア化し、推論結果をすぐ操作可能なメーターへ変換しました。

Today's focus is using Pose Landmarker not just as a skeleton renderer, but as a source for UI-ready metrics derived from a small set of landmarks. The official overview positions it for posture analysis and motion classification, with 33 normalized landmarks and world landmarks. This sample converts shoulder, hip, and ankle alignment into a small balance meter.

表現・インタラクションのアイデア

Expression and interaction idea

サンプルは Synthetic pose、Upload person image、Start camera、Freeze frame の入口を持ちます。MediaPipe が利用できる画像やカメラフレームでは実推論のランドマークを描き、合成ポーズでは fallback の 33 点で UI の読み方を確認できます。Minimum visibility で点の表示を絞り、Mirror overlay でセルフィー表示に近い左右反転を切り替えます。

The sample exposes Synthetic pose, Upload person image, Start camera, and Freeze frame paths. Real images and camera frames use MediaPipe inference when available, while the synthetic pose uses a 33-point fallback for understanding the UI. Minimum visibility filters landmarks and Mirror overlay approximates a selfie-style view.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

このサンプルで得られるランドマーク座標、visibility、肩と腰の傾き、足首と腰中心のずれ、reach span は、姿勢チェックや運動フォームの軽量ログになります。Hand Landmarker と組み合わせれば手先の到達領域、Image Segmenter と組み合わせれば人体マスク上の骨格表示、Object Detector と組み合わせれば道具を持った運動フォームの検出へ発展できます。Web Audio へ渡せばスコアに応じた音フィードバックも作れます。

The sample's landmark coordinates, visibility, shoulder and hip tilt, ankle-to-hip center offset, and reach span can become lightweight posture or exercise-form logs. Combined with Hand Landmarker it can track reach zones, with Image Segmenter it can overlay skeletons on a body mask, and with Object Detector it can inspect exercise form with equipment. Web Audio can turn scores into feedback sounds.

制作に使えそうな技術メモ

Production note

実装では `@mediapipe/tasks-vision@0.10.22` から `FilesetResolver` と `PoseLandmarker` を import し、`pose_landmarker_lite.task` を `createFromOptions()` で読み込みます。静止画、アップロード画像、カメラのフリーズフレームはいずれも Canvas に描いてから `detect(canvas)` に渡します。公式ガイドどおり同期推論なので、連続動画にする場合は `detectForVideo()` を Worker 側へ移す設計が必要です。

The implementation imports `FilesetResolver` and `PoseLandmarker` from `@mediapipe/tasks-vision@0.10.22`, then loads `pose_landmarker_lite.task` through `createFromOptions()`. Still images, uploads, and frozen camera frames are drawn to Canvas before calling `detect(canvas)`. Because inference is synchronous as described in the guide, continuous video should move `detectForVideo()` into a Worker.
