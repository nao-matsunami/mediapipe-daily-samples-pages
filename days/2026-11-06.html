サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

画像を保存せずに入力数、表示数、結果年齢、保留数、copy数、close時刻をPerformance APIやWorkerメッセージから集計できます。MediaPipe Image Segmenter、OffscreenCanvas、Web Audioの警告音、IndexedDBの同意済み集計、XR上の鮮度表示を組み合わせると、端末差の説明を作れます。

Count inputs, display age, pending slots, copies, and release times without retaining imagery; combine workers, canvas, audio, storage, and XR overlays.

制作に使えそうな技術メモ

Production note

ライブ経路では最新結果だけを表示候補にし、期限を越えた結果は描画しません。保存が要るときだけ必要最小限をcopyし、借用したbitmap/maskは同期処理の後に解放します。キューの深さ、結果age、copy、closeを別メトリクスにすると原因を切り分けやすくなります。今回の2本はモデルやネットワークを使わない設計検証です。

Use latest-only display, expire old results, copy only explicit snapshots, release borrowed resources after synchronous work, and measure each contract separately.

If you try one thing

俯瞰メモ

Bird's-eye memo

Web MLの長時間品質は平均FPSだけで決まりません。いま表示した結果がどれだけ新しいか、なぜ入力を捨てたか、何だけを履歴に残したかを説明できると、性能制御は利用者と運用者の双方にとって検証可能になります。

Long-session quality is not just average FPS: explain displayed age, admission decisions, and retained history.
