注目事例と何が面白いか

Notable example and why it matters

今日の注目は Gesture Recognizer の classifier options です。公式 API reference では running mode、手の検出・存在・追跡 confidence、canned / custom gesture classifier options、score threshold、allow / deny list が同じ設定面に並びます。面白いのは、gesture 名をそのまま UI 操作に割り当てるのではなく、許可する gesture、止める gesture、何フレーム続いたら確定するかを小さな policy layer として独立させられる点です。

Today's notable point is the Gesture Recognizer classifier options. The official API reference places running mode, hand detection/presence/tracking confidence, canned/custom gesture classifier options, score threshold, and allow/deny lists in the same configuration surface. The interesting part is that gesture names do not need to map directly to UI actions; allowed gestures, blocked gestures, and consecutive-frame confirmation can be isolated as a small policy layer.

表現・インタラクションのアイデア

Expression and interaction idea

本命サンプル `Gesture Classifier Policy Console` は、合成 top gesture の score を流し、allowlist / denylist / no list / invalid both lists、score threshold、confirm frames を動かして stable UI command を決めます。派生の `Gesture Zone Intent Mapper` は、同じ `Open_Palm` や `Victory` でも手の X 座標が left / center / right のどこにあるかで back、pin、next のように intent を変える小さな UI 実験です。

The main sample, `Gesture Classifier Policy Console`, streams synthetic top-gesture scores and lets you tune allowlist, denylist, no-list, invalid-both-list, score threshold, and confirmation frames before a stable UI command is selected. The derivative `Gesture Zone Intent Mapper` tests changing intent by hand X position, so the same `Open_Palm` or `Victory` gesture can become back, pin, or next depending on left, center, or right zones.

Possibilities unlocked by sample data and combinations

蓄積できるデータは、top gesture、score、policy mode、allow / deny list、confirm streak、fired command、hand X zone、zone dwell、gesture と zone の組み合わせ intent です。実 Gesture Recognizer、Hand Landmarker の landmark x/y、Web Audio の確認音、Pointer Lock なしの kiosk UI、WebRTC 配信 overlay、IndexedDB の操作ログ、LLM の command explanation と組み合わせると、誤操作を減らしたプレゼン操作、展示端末の非接触 UI、ジェスチャー練習フィードバック、複数人操作の arbitration に発展できます。

The samples can collect top gesture, score, policy mode, allow/deny list, confirmation streak, fired command, hand-X zone, zone dwell, and gesture-zone intent combinations. Combined with real Gesture Recognizer output, Hand Landmarker landmark x/y, Web Audio confirmation sounds, kiosk UI without Pointer Lock, WebRTC overlays, IndexedDB command logs, or LLM command explanations, this can grow into safer presentation controls, touchless exhibit terminals, gesture-practice feedback, or multi-user operation arbitration.

制作に使えそうな技術メモ

Production note

本命 HTML は `@mediapipe/tasks-vision@1.0.1/+esm` を dynamic import し、`GestureRecognizer` と `FilesetResolver` の export を軽く確認します。本番接続では `FilesetResolver.forVisionTasks()`、`GestureRecognizer.createFromOptions()`、`runningMode: "VIDEO"` または `"LIVE_STREAM"`、`recognizeForVideo()` か callback を接続します。UI への反映は top category だけでなく、score threshold、classifier allowlist / denylist、連続一致、cooldown、手の zone を別レイヤーに分けると調整しやすくなります。

The main HTML dynamically imports `@mediapipe/tasks-vision@1.0.1/+esm` and lightly checks the `GestureRecognizer` and `FilesetResolver` exports. A production connection would use `FilesetResolver.forVisionTasks()`, `GestureRecognizer.createFromOptions()`, `runningMode: "VIDEO"` or `"LIVE_STREAM"`, and either `recognizeForVideo()` or a callback. For UI updates, separate top category, score threshold, classifier allowlist/denylist, consecutive confirmation, cooldown, and hand zone into distinct layers.

試すならこれ

If you try one thing

`Gesture Classifier Policy Console` を開き、`Classifier policy` を allowlist、denylist、invalid both lists に切り替えてから `Start stream` を押します。invalid では設定衝突として候補が止まり、allowlist では選択 gesture だけが command になります。次に派生サンプルで `Victory` を選び、hand X を左から右へ動かすと、同じ gesture が previous slide、focus slide、next slide に分岐します。

Open `Gesture Classifier Policy Console`, switch `Classifier policy` between allowlist, denylist, and invalid both lists, then press `Start stream`. Invalid mode blocks candidates as a configuration conflict, while allowlist mode only turns selected gestures into commands. Then open the derivative sample, choose `Victory`, and move hand X from left to right to see the same gesture route to previous slide, focus slide, or next slide.
