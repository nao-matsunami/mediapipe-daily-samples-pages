注目事例と何が面白いか

Notable example and why it matters

今日の注目は、LLM の回答内容そのものではなく、Web UI が生成途中の partial result と cancel をどう扱うかです。公式 LLM Inference Web guide は streaming callback と multimodal prompt を示し、公式 sample は local model file、partial append、`cancelProcessing()` を持つ最小構成になっています。自作サンプルでは大容量モデルを要求せず、生成中、完了、途中停止、partial result retained の状態を可視化し、実モデル導入前に UI 契約を決められるようにしました。

Today's notable angle is not the generated answer itself, but how a Web UI handles partial results and cancellation during generation. The official LLM Inference Web guide shows streaming callbacks and multimodal prompts, while the official sample provides a compact local-model, partial-append, and `cancelProcessing()` flow. The original sample avoids requiring a large model and visualizes streaming, completion, cancellation, and retained partial results so the UI contract can be decided before real model integration.

表現・インタラクションのアイデア

Expression and interaction idea

Prompt Packet、Generated Response、Token Timeline、Generation Options、Run Log に分け、text / image / audio の入力片が出力余地をどう圧迫するかを触れる構成にしました。Start simulated stream で partial result が増え、Cancel processing で途中停止状態に移ります。timeline は text、image、audio、cancel を色で分け、WebGPU / CDN probe は実行環境の入口だけを確認します。

The interface is split into Prompt Packet, Generated Response, Token Timeline, Generation Options, and Run Log so users can feel how text / image / audio input pieces consume output budget. Start simulated stream grows partial results, and Cancel processing moves the run into a cancelled state. The timeline separates text, image, audio, and cancel events by color, while the WebGPU / CDN probe checks only the runtime entry point.

制作に使えそうな技術メモ

Production note

公式 sample のように local file から `modelAssetBuffer` を渡す形は、ユーザーが巨大モデルを自分で保持する検証 UI に向いています。一方で production では `modelAssetPath`、キャッシュ、進捗表示、WebGPU 非対応時の分岐が必要です。Streaming callback では partial result をそのまま DOM に追記するだけでなく、cancel 後に incomplete として保存するか破棄するかを state machine に入れておくと、誤って未完了出力を確定操作に使う事故を避けやすくなります。

Passing `modelAssetBuffer` from a local file, as in the official sample, fits validation UIs where users bring their own large model. Production paths still need `modelAssetPath`, caching, progress display, and a branch for browsers without WebGPU. In a streaming callback, partial results should not only be appended to the DOM; the state machine should decide whether incomplete cancelled output is saved or discarded so it is not accidentally used as a finalized action.
