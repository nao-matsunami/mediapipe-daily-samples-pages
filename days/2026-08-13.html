    The official guide frames the output as 543 total landmarks: 33 pose, 468 face, and 21 hand landmarks for each hand.

    The API reference calls out callback result lifetimes and synchronous detect mask-copy behavior, making data lifetime management important for continuous processing.

注目事例と何が面白いか

Notable example and why it matters

今日の注目は Holistic Landmarker を「全身ランドマークを全部描くデモ」ではなく、下流の操作を始めてよいかを判定する readiness meter として使うことです。公式 guide は pose、face、hand をまとめた 543 landmarks の統合 Task と説明しています。自作サンプルでは生成した人物ポーズを初期入力にし、必要ならカメラに切り替え、pose / face / hand のそろい具合を1つのスコアに畳み込みます。

Today's notable angle is using Holistic Landmarker not as a demo that draws every full-body landmark, but as a readiness meter deciding whether downstream interactions should start. The official guide describes it as a 543-landmark combined Task across pose, face, and hands. The original sample starts with a generated human pose, optionally switches to camera, and collapses pose / face / hand completeness into one score.

表現・インタラクションのアイデア

Expression and interaction idea

UI では open arms、cross body、side reach の生成ポーズ、hand visibility、face visibility、ready threshold を動かせます。ランドマーク群が十分そろうと READY、足りないと WAIT に変わるため、ジェスチャ UI、アバター入力、フィットネス判定の前段として「今の映像は使えるか」を表現できます。外部デモ一覧ではなく、生成入力と独自スコアリングを中心に置いています。

The UI lets you change generated poses between open arms, cross body, and side reach, plus hand visibility, face visibility, and ready threshold. It flips between READY and WAIT depending on whether landmark groups are complete enough, making it useful before gesture UI, avatar input, or fitness scoring. The focus is generated input plus custom scoring, not a list of external demos.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積できるデータは入力種別、pose shape、hand / face visibility、threshold、pose / face / hand のランドマーク数、group score、balance score、最終 readiness、latency、runtime です。Gesture Recognizer と組み合わせれば READY のときだけ手ジェスチャを採用できます。Face Landmarker の blendshapes とつなぐと avatar 制御に、Pose Landmarker の world landmarks とつなぐと距離や姿勢補正に、Web Audio とつなぐと入力品質の音フィードバックに発展します。

The sample can accumulate input type, pose shape, hand / face visibility, threshold, pose / face / hand landmark counts, group score, balance score, final readiness, latency, and runtime. Combined with Gesture Recognizer, hand gestures can be accepted only when READY. Connected to Face Landmarker blendshapes it can drive avatars, to Pose Landmarker world landmarks it can correct distance and posture, and to Web Audio it can provide input-quality sound feedback.

制作に使えそうな技術メモ

Production note

実装では `@mediapipe/tasks-vision@1.0.1` の `FilesetResolver` と `HolisticLandmarker` を任意 import し、HTTP 200 を確認した `holistic_landmarker.task` を `baseOptions.modelAssetPath` に渡します。読み込み前や失敗時は、33 pose、簡易 face ring、左右 21 hand の合成ランドマークを使って同じ overlay とスコアリングを動かします。公式 README の Holistic snippet にある `hand_landmark.task` は今回 404 だったため、model URL は実際に HEAD 確認してから固定しました。

The implementation optionally imports `FilesetResolver` and `HolisticLandmarker` from `@mediapipe/tasks-vision@1.0.1`, passing the HTTP-200 `holistic_landmarker.task` URL to `baseOptions.modelAssetPath`. Before loading or after failure, synthetic landmarks for 33 pose points, a simple face ring, and left / right 21-point hands keep the same overlay and scoring active. The `hand_landmark.task` path shown in the official README Holistic snippet returned 404 in this run, so the model URL was fixed only after a HEAD check.
