注目事例と何が面白いか

Notable example and why it matters

今日の注目は、Image Embedder の cosine similarity と Image Classifier の category score を、単発の推論結果ではなく「アプリが次に使う digest」へ変換することです。公式 guide は embedding や classification の作り方を示しますが、日次アーカイブ側では、連続フレームでほぼ同じ意味の結果を何度も送らず、merge / new / review / drop にまとめる最小 UI を作りました。

Today's notable point is turning Image Embedder cosine similarity and Image Classifier category scores into an application-ready digest instead of treating each inference result as a standalone event. The official guides show how to produce embeddings and classifications; this archive adds a minimal UI for merging near-duplicate semantic results into merge / new / review / drop routes.

表現・インタラクションのアイデア

Expression and interaction idea

本命の `Semantic Result Digest Board` は、合成 embedding vector と category score を流し、cosine merge threshold、score gate、scene drift、digest window を操作すると、類似フレームが digest bucket にまとまります。派生の `Action Payload Minimizer` は、分類・埋め込み・ランドマーク・ROI などの payload 候補を privacy strictness、bandwidth budget、confidence gate で send / summarize / review / block に振り分けます。

The main sample, `Semantic Result Digest Board`, streams synthetic embedding vectors and category scores; changing cosine merge threshold, score gate, scene drift, and digest window groups similar frames into digest buckets. The derivative, `Action Payload Minimizer`, routes candidate payloads such as categories, embeddings, landmarks, and ROI metadata through privacy strictness, bandwidth budget, and confidence gates into send / summarize / review / block.

制作に使えそうな技術メモ

Production note

実 Task に接続する時は、Image Embedder の float / quantized embedding 差、cosine threshold、Image Classifier の `maxResults` と score threshold、Worker での同期推論、フレーム送信頻度、古い digest の TTL を分けて測ります。外部送信では raw image や full embedding を初期値にせず、label、score、短い semantic digest、必要なら ROI metadata までに抑える設計が扱いやすいです。

When connecting real tasks, measure float versus quantized embeddings, cosine thresholds, Image Classifier `maxResults` and score thresholds, synchronous worker inference, frame send cadence, and digest TTL separately. For external transmission, avoid starting with raw images or full embeddings; prefer labels, scores, short semantic digests, and ROI metadata only when needed.
