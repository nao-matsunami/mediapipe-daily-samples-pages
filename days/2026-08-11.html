注目事例と何が面白いか

Notable example and why it matters

今日の注目は Image Classifier を、外部写真の説明ではなく「画面内で生成した素材がどんなラベルに寄るか」を測る小さなプローブとして使うことです。公式 Web guide は `FilesetResolver.forVisionTasks()` で WASM を解決し、EfficientNet-Lite0 の model path を `ImageClassifier.createFromOptions()` に渡す流れを示しています。今日の自作サンプルでは3枚のキャンバスを生成し、シーン、ノイズ、seed、score threshold を変えながら分類結果の変化を観察します。

Today's notable angle is using Image Classifier as a small probe for generated on-screen materials rather than as a description layer for external photos. The official Web guide shows resolving WASM with `FilesetResolver.forVisionTasks()` and passing the EfficientNet-Lite0 model path to `ImageClassifier.createFromOptions()`. Today's original sample generates three canvases and lets you adjust scene, noise, seed, and score threshold while watching classification changes.

表現・インタラクションのアイデア

Expression and interaction idea

Garden object、Kitchen shape、Road sign の3つの生成シーンを切り替え、ノイズと seed で同じ構図のゆらぎを作ります。Classify ボタンで現在の3枚を再評価し、score threshold を動かすと通過ラベル数と top label が即時に変わります。Load MediaPipe が成功した環境では EfficientNet-Lite0 の実ラベル、失敗した環境では fallback の warm / cool / bright / edge スコアで同じ UI の挙動を確認できます。

Switch between Garden object, Kitchen shape, and Road sign scenes, then use noise and seed to create variations of the same composition. The Classify button reevaluates the current three canvases, and moving the score threshold immediately changes the number of passed labels and the top label. When Load MediaPipe succeeds, the UI shows real EfficientNet-Lite0 labels; otherwise the same interaction is available through fallback warm / cool / bright / edge scores.

制作に使えそうな技術メモ

Production note

実装では CDN の `@mediapipe/tasks-vision@1.0.1` から `FilesetResolver` と `ImageClassifier` を読み、hosted EfficientNet-Lite0 float32 model を `runningMode: "IMAGE"`、`maxResults: 5`、可変 `scoreThreshold` で使う経路を用意しました。公式ドキュメントの通り `classify()` は同期的に返るため、今日の試作は3枚の still canvas に限定しています。カメラや連続生成フレームで使うなら Worker に分離し、`classifyForVideo()` と timestamp 管理に切り替えるのが次の実装ポイントです。

The implementation loads `FilesetResolver` and `ImageClassifier` from CDN `@mediapipe/tasks-vision@1.0.1`, using the hosted EfficientNet-Lite0 float32 model with `runningMode: "IMAGE"`, `maxResults: 5`, and a variable `scoreThreshold`. As the official docs note, `classify()` returns synchronously, so today's prototype limits itself to three still canvases. For camera or continuously generated frames, the next implementation step is to move inference into a Worker and switch to `classifyForVideo()` plus timestamp handling.
