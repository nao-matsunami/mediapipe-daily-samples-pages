表現・インタラクションのアイデア

Expression and interaction idea

本命は、描画のたびに推論せず、1秒あたりの予約回数と推論コストから次の開始時刻を決めます。黄色の現在位置と紫の最後に受理した結果のずれが、遅延を視覚的なリズムにします。派生は、二つの候補のscoreだけではなく直前位置への近さを使い、誰の手・姿勢を操作対象として引き継ぐかを触って比較できます。

The main turns inference timing into a visible rhythm; the derivative compares score-only selection with continuity-first candidate handoff.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

推論開始・完了・採用・破棄の時刻、結果年齢、推論コスト、候補ごとのscore、重心、handedness、presence、引き継ぎ理由を小さなイベントとして保存できます。Performance APIとLong Tasks、IndexedDBの上限付きセッションログ、Web Audioの拍、WebXRの空間アンカーを組み合わせると、端末別の予算や『人が切り替わったと感じる』閾値を比較できます。

Start/finish/adopt/drop timings, age, cost, scores, centroids, handedness, and handoff reasons can combine with performance, storage, audio, and XR signals.

制作に使えそうな技術メモ

Production note

実装ではvideoの描画ループとdetectForVideoの開始を分離し、未完了中に新しい要求を積まないか、最新フレームだけを保つかを明示します。結果オブジェクトやmaskは所有期間を短くし、Taskのcloseとvideo track停止を画面離脱時に行います。複数人物ではscore最大へ即切替せず、位置・手性・ID・不在時間を含む切替余白を置くと、操作対象が跳びにくくなります。

Separate rendering from task starts, state a queue policy, keep result ownership short, clean up tasks/tracks, and add a margin around multi-person handoffs.

試すならこれ

If you try one thing

本命で推論コストを上げ、毎秒予算を下げて、現在位置と最後のML結果の距離を比べます。派生では点Aを点Bへ近づけ、scoreの重みを上げ下げして、誤った乗り換えと追従性の境目を見ます。

Raise main-task cost and lower its rate, then steer A toward B and tune score weight to find handoff boundaries.

俯瞰メモ

Bird's-eye memo

Web MLのUI品質は最高精度の1フレームだけでは決まりません。結果の時刻、資源の寿命、誰を同じ対象と見なすかという時間方向の約束が、体感上の信頼を作ります。小さなスケジューラと引き継ぎ規則を先に可視化すると、後からモデルやデリゲートを替えても検証軸を保てます。

Live Web ML trust comes from temporal promises about time, resource lifetime, and identity—not merely the best single-frame score.

今日のミニ試作候補

Today's mini prototype candidate

本命 `Inference Budget Conductor` は、ポインタ由来の現在位置に対して、推論コストと毎秒予算で最後の受理結果を遅れて追わせます。何が動くか: コスト・予算・速度を操作し、予約回数、スキップされた描画、結果遅延を観察できます。次に足すなら実MediaPipe Task、Worker、Performance markです。派生 `Landmark Handoff Compass` は、二つの擬似ランドマーク候補をscoreと位置連続性で選びます。何が動くか: ポインタでAを動かし、切替余白と重みで追跡対象の乗り換えを比較できます。次に足すなら実Hand/Pose Landmarkerの重心、handedness、presence、再取得ログです。

Inference Budget Conductor paces accepted results; Landmark Handoff Compass selects between candidates using score and continuity.
