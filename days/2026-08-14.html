注目事例と何が面白いか

Notable example and why it matters

今日の注目は Text Classifier を単なる sentiment 表示ではなく、短いプロダクト文言を採用してよいかの gate に変換することです。公式ガイドは positive / negative のようなモデル定義カテゴリを返す Task と説明しています。自作サンプルでは3本の draft を同時に編集し、positive score から negative score を引いた margin がしきい値を超えたものだけ PASS にします。

Today's notable angle is turning Text Classifier from a sentiment display into a gate for deciding whether short product copy is acceptable. The official guide describes the task as returning model-defined categories such as positive / negative. The original sample edits three drafts at once and marks only drafts whose positive-minus-negative margin clears the threshold as PASS.

表現・インタラクションのアイデア

Expression and interaction idea

UI では release notes、support reply、onboarding の preset を切り替え、3本の文言を textarea で直接編集できます。Positive gate、rewrite pressure、max results を動かすと、PASS / REWRITE、positive / negative bar、best margin、accepted count が即時に変わります。外部デモ一覧ではなく、文言調整と採用判定という自作の作業面を中心にしました。

The UI switches between release notes, support reply, and onboarding presets, with three editable textareas. Moving positive gate, rewrite pressure, and max results updates PASS / REWRITE, positive / negative bars, best margin, and accepted count immediately. The focus is the original copy-tuning workspace and acceptance decision, not an external demo list.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積できるデータは draft text、preset、positive / negative score、margin、threshold、rewrite pressure、採用可否、runtime、編集イベントです。Language Detector と組み合わせれば言語別 gate、Text Embedder と組み合わせればブランド文言との近さ、LLM と組み合わせれば REWRITE の文案生成、IndexedDB と組み合わせれば日次のコピー品質ログにできます。Web Speech API で読み上げを足すと、音声案内のトーン検証にも広がります。

The sample can accumulate draft text, preset, positive / negative score, margin, threshold, rewrite pressure, acceptance, runtime, and edit events. Combined with Language Detector it can create locale-specific gates, with Text Embedder it can measure closeness to brand copy, with an LLM it can generate rewrite candidates, and with IndexedDB it can keep daily copy-quality logs. Adding Web Speech API would extend this to tone checks for spoken guidance.

制作に使えそうな技術メモ

Production note

実装では `@mediapipe/tasks-text@latest/text_bundle.js` を読み込み、`FilesetResolver.forTextTasks()` に latest wasm root を渡し、BERT classifier model を `baseOptions.modelAssetPath` に指定します。`classify(text)` の戻り値から categories を取り出し、positive と negative の score 差を margin に変換します。2026-08-14 の確認では `@latest` は 1.0.1、wasm root と model は HTTP 200、`@mediapipe/tasks-text@0.10.22` は 404 でした。

The implementation loads `@mediapipe/tasks-text@latest/text_bundle.js`, passes the latest wasm root to `FilesetResolver.forTextTasks()`, and points `baseOptions.modelAssetPath` at the BERT classifier model. It extracts categories from `classify(text)` and converts the positive / negative score difference into a margin. On 2026-08-14, `@latest` resolved to 1.0.1, the wasm root and model returned HTTP 200, and `@mediapipe/tasks-text@0.10.22` returned 404.
