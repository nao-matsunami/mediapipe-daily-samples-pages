表現・インタラクションのアイデア

Expression and interaction idea

本命 `ROI Scope Truth Table` は ROI の位置と幅を動かし、入力切り出し、推論候補、結果表示の三段で何が変わるかを示します。派生 `Label Locale Fallback Lens` は希望 locale と fallback 方針を変え、metadata の表示名がない時に英語または stable category ID へ落ちる経路を見せます。

The main ROI table moves a region and shows changes at crop, inference-candidate, and display stages. The derivative lens changes requested locale and fallback policy, exposing the route to English or a stable category ID when metadata lacks a display name.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

保存するなら画像や camera frame ではなく、正規化ROI、model hash、candidate 数、処理時間、locale、選ばれた fallback 種別だけにします。Performance API、ImageBitmap、Web Worker、MediaPipe Task の結果、アクセシビリティ用 aria-label、CMS の翻訳辞書と組み合わせれば、端末内の視覚推論を観察可能な制作ツールへ発展できます。

Retain normalized ROI, model hash, candidate count, processing time, locale, and chosen fallback type—not images or camera frames. Combined with Performance API, ImageBitmap, Web Worker, Task results, accessible aria-labels, and a CMS translation dictionary, this can become an inspectable local visual-inference tool.

制作に使えそうな技術メモ

Production note

ROI がモデル入力の crop なのか、検出後の filter なのか、単なる overlay clip なのかをAPI契約と計測で分けます。座標変換は表示、原画像、回転済み入力の各空間を明示します。ラベルは model metadata の display name、利用者locale、fallback locale、category ID を別フィールドにし、機械翻訳をモデルの公式表示名のように表示しません。

Separate whether ROI is an input crop, post-detection filter, or display clip using the API contract and measurement. Name display, source-image, and rotated-input coordinate spaces. Keep metadata display name, user locale, fallback locale, and category ID as distinct fields; do not present machine translation as an official model label.

俯瞰メモ

Bird's-eye memo

Web ML のUIは推論結果を飾るだけでなく、どのpixelsを渡したのか、どの言語名を信頼したのかという来歴を伝える層です。高速化や多言語化は、その経路を隠すほど検証しづらくなります。

Web ML UI is not just decoration for results: it communicates which pixels were supplied and which language label was trusted. Performance and localization become harder to verify when that path is hidden.
