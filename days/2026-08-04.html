今日の重要トピック

  1. Object Detector は画像内の複数クラスの物体位置を bounding box とカテゴリスコアで返す MediaPipe Tasks の Vision タスク。

    Object Detector is a MediaPipe Tasks vision task that returns object locations as bounding boxes with category scores.

  2. Web 実装では `@mediapipe/tasks-vision`、`FilesetResolver.forVisionTasks()`、`ObjectDetector.createFromOptions()`、EfficientDet Lite モデルを組み合わせる。

    The web implementation combines `@mediapipe/tasks-vision`, `FilesetResolver.forVisionTasks()`, `ObjectDetector.createFromOptions()`, and an EfficientDet Lite model.

  3. 公式 Web ガイドは `scoreThreshold`、`maxResults`、`displayNamesLocale`、allowlist / denylist など、結果の量と意味を調整するオプションを示している。

    The official web guide documents options such as `scoreThreshold`, `maxResults`, `displayNamesLocale`, allowlists, and denylists for shaping result quantity and meaning.

  4. `detect()` / `detectForVideo()` は同期実行で UI スレッドをブロックし得るため、ライブカメラ化するなら Worker 分離が重要になる。

    `detect()` and `detectForVideo()` run synchronously and can block the UI thread, so live-camera use should move inference into a Worker.

  5. 今日の試作は公式デモ一覧ではなく、自作の合成シーン、アップロード、カメラフリーズ、閾値スライダー、検出リストを中心にした。

    Today's prototype centers an original synthetic scene, upload path, camera freeze, threshold slider, and detection list rather than external demo cards.

注目事例と何が面白いか

Notable example and why it matters

今日の注目は MediaPipe Object Detector です。Image Segmenter がピクセル単位の領域を返すのに対し、Object Detector は物体単位の候補を bounding box とスコアで返すため、クリック候補、検索対象、在庫カウント、注釈作成などの UI の入口になります。スコア閾値を少し変えるだけで、画面上に残る候補数と上位ラベルが変わるところが試作向きです。

Today's focus is MediaPipe Object Detector. Unlike Image Segmenter, which returns pixel-level regions, Object Detector returns object-level candidates as bounding boxes and scores, making it a useful entry point for click suggestions, search targets, inventory counts, and annotation tools. Small threshold changes visibly alter the remaining candidates and top label, which makes it well suited to a compact prototype.

表現・インタラクションのアイデア

Expression and interaction idea

自作サンプルでは、合成された机上シーンに対して box overlay と検出リストを出し、scoreThreshold と maxResults をスライダーで変えられるようにしました。アップロード画像やカメラのフリーズフレームでも同じ表示を使えるため、同じ UI で合成入力と実入力を比較できます。トップラベル、推論時間、検出数を右側に固定し、閾値を動かしたときの変化を読みやすくしています。

The original sample renders box overlays and a detection list on a synthetic desktop scene, with sliders for scoreThreshold and maxResults. Uploaded images and frozen camera frames use the same display, so synthetic and real inputs can be compared through one UI. Top label, inference time, and detection count stay pinned on the right to make threshold changes easy to read.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

このサンプルで蓄積できる bounding box、カテゴリ名、スコア、閾値、入力種別、推論時間は、検出 UI の品質ログになります。Interactive Segmenter と組み合わせると box 内のクリック候補を提示でき、Image Segmenter と組み合わせると box と mask の一致度を見られます。Web Speech API で「赤い物体を探して」のような入力を受けたり、LLM に検出リストを渡して写真内の要約や確認質問を作らせたりする発展もできます。

The sample can accumulate bounding boxes, category names, scores, thresholds, input type, and inference time as quality logs for detection UI. Paired with Interactive Segmenter, boxes can suggest click targets; paired with Image Segmenter, box-mask agreement can be inspected. It can also take commands through the Web Speech API or pass detection lists to an LLM for image summaries and clarification questions.

制作に使えそうな技術メモ

Production note

Web 版は `FilesetResolver.forVisionTasks()` で WASM を読み、`ObjectDetector.createFromOptions()` に `modelAssetPath`、`scoreThreshold`、`maxResults`、`runningMode: "IMAGE"` を渡します。今回のサンプルは Canvas に入力を描いてから `detector.detect(canvas)` を呼び、返ってきた `boundingBox` と `categories[0].score` を別 Canvas に描画しました。公式モデルや CDN が取れない場合でも合成シーン用の fallback boxes を表示し、レイアウトと検証項目を確認できるようにしています。

The web version loads Wasm with `FilesetResolver.forVisionTasks()` and passes `modelAssetPath`, `scoreThreshold`, `maxResults`, and `runningMode: "IMAGE"` to `ObjectDetector.createFromOptions()`. This sample draws the chosen input into a Canvas, calls `detector.detect(canvas)`, and renders returned `boundingBox` and `categories[0].score` values on a second Canvas. If the official model or CDN is unavailable, fallback boxes for the synthetic scene keep the layout and inspection flow usable.

If you try one thing

Then upload a desk or shelf photo and move maxResults from 1 to 8 to compare a top-candidate UI with a candidate-list UI. In a camera-enabled environment, Start camera and Freeze frame feed the same detection flow.
