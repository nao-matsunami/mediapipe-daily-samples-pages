注目事例と何が面白いか

Notable example and why it matters

今日の注目は、Image Segmenter の結果が「推論できた」で終わらず、その後に mask をどう合成し続けるかで UI の軽さが大きく変わる点です。category mask / confidence mask を毎フレーム全面描画するのか、変化した tile だけを送るのか、worker や OffscreenCanvas に渡すのかを分けて考えると、公式デモから実アプリへ移すときの設計判断が見えやすくなります。

Today's notable point is that Image Segmenter output does not end at successful inference; UI responsiveness depends on how masks keep being composited afterward. Thinking separately about full-frame category / confidence mask drawing, changed-tile transfer, and worker / OffscreenCanvas handoff makes the design choices clearer when moving from official demos to real apps.

表現・インタラクションのアイデア

Expression and interaction idea

本命サンプル `Mask Delta Compositor Lab` は mask mode、render policy、tile size、motion、confidence gate、frame budget を動かすと、full / delta / skip の route と合成コストが変わります。派生の `Mask Tile Scheduler Playground` は bandwidth、TTL、sensitivity、priority mode から各 tile を send / hold / reuse / drop に振り分け、mask 更新を queue として見る感覚を作ります。

The main sample, `Mask Delta Compositor Lab`, changes the full / delta / skip route and compositing estimate as mask mode, render policy, tile size, motion, confidence gate, and frame budget are adjusted. The derivative, `Mask Tile Scheduler Playground`, routes each tile to send / hold / reuse / drop from bandwidth, TTL, sensitivity, and priority mode, making mask updates feel like a queue.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積できるデータは mask mode、tile size、changed tile count、full / delta cost、paint budget、skip count、tile age、send / hold / reuse / drop decision です。Image Segmenter、Interactive Segmenter、Pose Landmarker segmentation mask、Canvas 2D、OffscreenCanvas、Web Worker、ImageBitmap、WebGL texture atlas、PerformanceObserver、Long Task API、IndexedDB と組み合わせると、端末別に mask 更新ポリシーを記録し、描画が重い時だけ delta 合成へ切り替える実験ができます。

The samples can accumulate mask mode, tile size, changed tile count, full / delta cost, paint budget, skip count, tile age, and send / hold / reuse / drop decisions. Combined with Image Segmenter, Interactive Segmenter, Pose Landmarker segmentation masks, Canvas 2D, OffscreenCanvas, Web Workers, ImageBitmap, WebGL texture atlases, PerformanceObserver, the Long Task API, and IndexedDB, an app can record per-device mask update policy and switch to delta compositing only when painting gets expensive.

制作に使えそうな技術メモ

Production note

実装時は、推論時間、mask 転送、canvas paint、古い bitmap / texture の破棄を別々に計測します。`segmentForVideo()` の結果をすぐ UI thread で全面描画する設計は単純ですが、解像度と FPS が上がると Long Task の温床になります。mask を tile 化し、変化量と TTL で送信優先度を決めると、見た目の鮮度と描画予算を交換しやすくなります。

In implementation, measure inference time, mask transfer, canvas paint, and disposal of stale bitmaps / textures separately. Drawing a full mask on the UI thread immediately after `segmentForVideo()` is simple, but higher resolution and FPS can create long tasks. Tiling the mask and prioritizing transfer by change amount and TTL makes visual freshness easier to trade against paint budget.

試すならこれ

If you try one thing

In the derivative, low bandwidth and low sensitivity increase hold decisions, while a short TTL increases drops, making mask updates easier to understand as an in-frame queue.
