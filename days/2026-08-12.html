Face Detector で顔領域のプライバシーゲートを作る

Build a face-region privacy gate with Face Detector

MediaPipe Tasks Face Detector の Web 実装を参考に、生成ポートレートまたはカメラ映像から顔 bbox、6つの顔キーポイント、confidence、latency を表示する自作サンプルを追加しました。MediaPipe を読み込める環境では BlazeFace short range model を使い、読み込めない環境でも肌色領域の fallback 推定で同じ閾値ゲート UI が動きます。

注目事例と何が面白いか

Notable example and why it matters

今日の注目は Face Detector を「顔を見つけるデモ」ではなく、顔領域を見つけたときだけ UI を開くプライバシーゲートとして使うことです。公式 Web guide は `FilesetResolver.forVisionTasks()` で WASM を解決し、Face Detector に model asset path と running mode を渡す流れを示しています。自作サンプルでは生成ポートレートを初期入力にし、任意でカメラに切り替えて bbox、6点、confidence、latency を同じ画面で確認します。

Today's notable angle is using Face Detector not as a generic face-finding demo, but as a privacy gate that opens UI only when a face region passes confidence. The official Web guide shows resolving WASM with `FilesetResolver.forVisionTasks()` and passing a model asset path plus running mode to Face Detector. The original sample starts from a generated portrait and optionally switches to camera, showing bbox, six keypoints, confidence, and latency on one surface.

表現・インタラクションのアイデア

Expression and interaction idea

Synthetic portrait、Camera、confidence slider、pose / seed controls を用意し、顔候補が閾値を超えたときだけ gate を open にします。MediaPipe を読み込める環境では BlazeFace の検出結果を緑、fallback 推定は赤で描き分けます。閾値を上げると表示が閉じるため、顔検出を「検出結果の可視化」から「入力品質や同意状態を示すインタラクション」に変えられます。

The UI includes Synthetic portrait, Camera, confidence slider, and pose / seed controls, opening the gate only when a candidate passes the threshold. MediaPipe results are drawn in green, while fallback estimates are drawn in red. Raising the threshold closes the display, turning face detection from simple result visualization into an interaction that communicates input quality or consent state.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積できるデータは入力種別、生成 seed、pose、bbox、6点キーポイント、score、threshold、gate 状態、latency、runtime です。Face Landmarker と組み合わせると、Face Detector は低コストな前段 ROI として使えます。Image Segmenter や Interactive Segmenter と接続すれば顔領域だけをぼかす、背景だけを残す、検出された顔を匿名 avatar に差し替えるなどの UI に発展します。Web Worker と OffscreenCanvas を足すと、カメラ処理の同期ブロックを避けながら同じ gate を維持できます。

The sample can accumulate source type, generation seed, pose, bbox, six keypoints, score, threshold, gate state, latency, and runtime. Combined with Face Landmarker, Face Detector becomes a low-cost ROI stage. Connected to Image Segmenter or Interactive Segmenter, it can blur only faces, preserve only backgrounds, or replace detected faces with anonymous avatars. Adding Web Workers and OffscreenCanvas can keep the same gate while avoiding synchronous camera blocking.

制作に使えそうな技術メモ

Production note

実装では CDN の `@mediapipe/tasks-vision@1.0.1` から `FilesetResolver` と `FaceDetector` を任意 import し、hosted BlazeFace short range float16 model を `runningMode: "IMAGE"` / `"VIDEO"` で切り替えます。`minDetectionConfidence` は slider の値を反映し、`minSuppressionThreshold` は 0.3 に固定しました。MediaPipe が使えない場合でも、キャンバスのピクセルから肌色らしい最大領域を拾い、bbox と6点を合成する fallback で UI の検証を続けられます。

The implementation optionally imports `FilesetResolver` and `FaceDetector` from CDN `@mediapipe/tasks-vision@1.0.1`, switching the hosted BlazeFace short range float16 model between `runningMode: "IMAGE"` and `"VIDEO"`. `minDetectionConfidence` follows the slider, while `minSuppressionThreshold` is fixed at 0.3. If MediaPipe is unavailable, a fallback scans canvas pixels for the largest skin-like region and synthesizes bbox plus six points so the UI remains testable.
