表現・インタラクションのアイデア

Expression and interaction idea

本命 `Mask Lease Frame Lab` は、擬似 mask を同一フレームで描画・解放するか、次フレーム用に copy するかを切り替え、期限切れ参照と予算超過を数えます。派生 `ROI Handoff Smoother` はドラッグした raw ROI と滑らかな handoff ROI を重ね、反応性と安定性のトレードオフを触って確かめます。

The main `Mask Lease Frame Lab` switches between drawing/releasing a synthetic mask in the same frame or copying it for the next, counting expired references and budget overruns. The derivative `ROI Handoff Smoother` overlays dragged raw and smooth handoff ROIs to make responsiveness versus stability tangible.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積するなら raw pixel や完全な mask ではなく、frame timestamp、mask の解像度、copy の有無、描画時間、ROI 中心・幅、score bin、再検出理由までに絞ります。Performance API、OffscreenCanvas、Web Worker、ImageBitmap、IndexedDB の短い TTL、Task の presence / confidence を組み合わせると、端末内で「なぜ追従が遅れたか」を再現する小さな診断面になります。

If anything is retained, keep only frame timestamps, mask dimensions, copy decision, render time, ROI center/width, score bin, and reacquisition reason—not raw pixels or full masks. Performance API, OffscreenCanvas, Web Worker, ImageBitmap, short IndexedDB TTL, and Task presence/confidence can become a local diagnostic surface for delayed tracking.

制作に使えそうな技術メモ

Production note

Task callback の mask は callback 内で overlay まで済ませる設計を基本にし、次フレームや別 worker に渡す必要がある場合だけ独立表現へ copy します。copy は解像度と頻度を計測し、古い frame の結果は generation / timestamp で落とします。ROI は正規化座標で保存し、clamp、平滑化、低 score 時の保持、一定時間後の再検出を別々に調整します。

Make callback-local overlay the default for Task masks; copy to an independent representation only when another frame or worker needs it. Measure copy by resolution and rate, dropping old results by generation/timestamp. Store ROI in normalized coordinates and tune clamp, smoothing, low-score hold, and timed reacquisition separately.

試すならこれ

If you try one thing

本命で負荷を 24ms、予算を 16ms にして連続実行し、copy を on / off で切り替えてください。予算超過と資源の持ち越しが別問題だと分かります。派生では追従率を 0.10 と 0.70 に変え、素早いポインタ移動で手ぶれと遅れの境目を見ます。

In the main sample set load to 24ms and budget to 16ms, run continuously, and toggle copy on/off. It separates deadline misses from resource carryover. In the derivative, compare 0.10 and 0.70 follow rates while moving quickly to see the boundary between jitter and lag.

俯瞰メモ

Bird's-eye memo

このアーカイブの焦点は、モデルの出力を増やすことから、出力がいつ有効で、いつ捨て、どう次の操作に受け渡すかを設計することへ移っています。Web ML の軽快さは、モデル速度だけでなく、資源の寿命を正直に扱い、遅れを視覚的に説明できることから生まれます。

The archive is shifting from adding model outputs to designing when output is valid, when it is discarded, and how it moves to the next interaction. Web ML responsiveness comes not only from model speed but from honest resource lifetimes and explainable delay.
