注目事例と何が面白いか

Notable example and why it matters

今日の注目は Image Segmenter と Interactive Segmenter の境界です。Image Segmenter は画像全体をカテゴリ別に分けるため、人物背景差し替えや DeepLab-V3 的な一般物体マスクに向きます。一方 Interactive Segmenter はクリック位置を手がかりに対象物だけを切るので、編集 UI やアノテーション UI に近い発想で使えます。面白いのは、モデルそのものよりも mask をどう表示し、どのしきい値で action に変えるかが体験品質を左右する点です。

Today's notable area is the boundary between Image Segmenter and Interactive Segmenter. Image Segmenter divides a full image into categories, making it suitable for person/background replacement or DeepLab-V3-style general object masks. Interactive Segmenter uses a click location to isolate a selected object, which fits editing and annotation interfaces. The interesting part is that experience quality depends less on the model alone and more on how the mask is displayed and thresholded into actions.

表現・インタラクションのアイデア

Expression and interaction idea

今日のサンプルは、人物風の合成ソース画像と confidence mask 風の生成マスクを fallback として持ちつつ、`Start Camera` で selfie segmenter model と webcam を起動し、`segmentForVideo()` の confidence mask を同じ Composite / Mask / Edges / Source UI に流し込めるようにしました。Threshold を上げると切り抜きが細り、Feather を上げると境界が柔らかくなり、Edge gain で輪郭の見え方を調整できます。

Today's sample keeps a portrait-like synthetic source and confidence-mask fallback, while `Start Camera` loads the selfie segmenter model and webcam and feeds `segmentForVideo()` confidence masks into the same Composite / Mask / Edges / Source UI. Raising Threshold narrows the cutout, increasing Feather softens the boundary, and Edge gain adjusts contour visibility.

制作に使えそうな技術メモ

Production note

Web の Image Segmenter では `FilesetResolver.forVisionTasks()` で Wasm を解決し、`ImageSegmenter.createFromOptions()` に model asset と `runningMode` を渡します。静止画なら `segment(image, callback)`、動画なら `segmentForVideo(videoFrame, timestamp, callback)` を使います。公式 API は戻り値コピー版も用意していますが、高頻度処理では callback 中の mask lifetime を意識した描画パスにした方が余計なコピーを避けやすいです。

On the web, Image Segmenter resolves Wasm with `FilesetResolver.forVisionTasks()` and passes the model asset plus `runningMode` into `ImageSegmenter.createFromOptions()`. Use `segment(image, callback)` for still images and `segmentForVideo(videoFrame, timestamp, callback)` for video. The API also offers copied-return variants, but high-frequency processing should prefer a callback-based rendering path that respects mask lifetime and avoids extra copies.
