表現・インタラクションのアイデア

Expression and interaction idea

本命では人物の右手、入力フレーム、Taskラベル、画面位置を同時に変えます。CSS鏡像だけと入力反転を独立したボタンにしたので、「画面左」を発話したいのか「TaskのLeft」を使いたいのかを選べます。派生では👍/✌️を二回連続で送らないと行動にしません。

The main independently toggles preview mirroring and input flipping; the derivative requires repeated gesture evidence before action.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

保存せずにtimestamp、categoryName、score、入力反転フラグ、表示側、ガード通過数だけを集計できます。Hand Landmarkerの21点、Gesture Recognizer、WebHIDの物理スイッチ、Web Audioの確認音、XRの視野内ラベル、匿名のIndexedDB統計を組み合わせると、環境ごとの誤作動を画像なしで比較できます。

Aggregate timestamps, labels, scores, flip state, screen side, and guard outcomes without storing imagery; combine landmarks, WebHID, audio, XR, and consented local statistics.

制作に使えそうな技術メモ

Production note

入力ピクセルを反転する処理と、CSS transformでプレビューだけを鏡像にする処理を混ぜません。UIには「画面左」「入力のLeft」「人物の右手」を明記します。ジェスチャーはscore閾値だけでなく、同一結果の連続回数、結果age、クールダウン、キーボード等の代替操作を設けます。今回の2本はモデル・カメラを使わない設計検証です。

Do not conflate pixel flips with CSS mirroring. Label each coordinate/meaning frame explicitly and gate gesture actions with more than a score threshold.

俯瞰メモ

Bird's-eye memo

Web MLの操作性は精度だけで決まりません。モデルが見た座標、利用者が見た座標、プロダクトが行動に変えた判断を追跡できれば、鏡像カメラでも誤解をUIで解けます。分類器の出力は命令ではなく、次の判断への証拠として扱うのが安全です。

Usability depends on traceable meanings across model input, user display, and product action; a classifier output is evidence, not an order.
