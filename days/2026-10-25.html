表現・インタラクションのアイデア

Expression and interaction idea

本命は欠損帯と受信点をタイムラインに並べ、保持猶予より短い欠損をHOLD、超える欠損をOFFとして見せます。派生は同じ考えをoverlayの色、破線、年齢バーに翻訳します。ユーザーが『検出なし』と『前の結果を表示中』を区別できます。

The main maps gaps to LIVE/HOLD/OFF. The derivative translates the same contract into overlay color, dashes, and an age bar.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

保存するなら映像ではなく、media time、Task result timestamp、受信時刻、presence、結果年齢、保持期限、OFF遷移理由を最小単位にします。MediaPipe Face/Holistic/Pose Task、Performance API、Web Worker、Canvas/WebGL overlay、Web Audioの警告音、同意済み診断を組み合わせれば、端末差と背景復帰時の時系列品質を比較できます。

Store media time, result timestamp, receipt time, presence, age, hold limit, and OFF reason—not video. Combine Tasks with Performance API, Workers, overlays, audio, and consented diagnostics.

制作に使えそうな技術メモ

Production note

実装では結果 timestamp、video.currentTime、JavaScript受信時刻を混同しません。最後の有効結果を持つなら最大年齢を決め、超過後は描画を止めるか明示的にstale化します。新しい映像源やTask再初期化ではsession IDも併用し、古い完了を採用しません。公式privacy noticeのとおり入力は端末処理でも、利用・性能メトリクスの設計は別途確認します。

Keep result timestamps, media time, and receipt time separate. Bound holds, make stale states explicit, and use session IDs across lifecycle changes. Metrics need their own privacy review.

俯瞰メモ

Bird's-eye memo

Web MLの連続性は、モデルの出力頻度だけでは決まりません。結果が欠けた時、前回の値が何ms古いか、いつ表示を止めるかを表現層で共有すると、推論改善と不確実さの説明を両立できます。

Web ML continuity depends on more than output frequency. Shared result-age and stop rules let UI explain uncertainty without hiding it.
