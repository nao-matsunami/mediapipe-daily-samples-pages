注目事例と何が面白いか

Notable example and why it matters

今日の注目は、Interactive Segmenter を「クリックしたらマスクが出る demo」ではなく、ユーザーの修正意図を stroke protocol として扱うことです。公式 Web README は `BrushMode.POSITIVE` の stroke points と `isCompleted` を渡す最小例を示し、mediapipe-samples-web は accumulated strokes、worker、request invalidation、mask bitmap close まで含んでいます。つまり実装の面白さはモデル呼び出しだけでなく、positive / negative / box / lasso の順序、古い request の破棄、点列の圧縮にあります。

Today's notable angle is treating Interactive Segmenter not as a click-to-mask demo, but as a stroke protocol for user correction intent. The official Web README shows a minimal `BrushMode.POSITIVE` stroke with points and `isCompleted`, while mediapipe-samples-web includes accumulated strokes, workers, request invalidation, and closing mask bitmaps. The interesting implementation work is therefore not just model invocation, but the ordering of positive / negative / box / lasso instructions, stale request rejection, and point-stream compression.

表現・インタラクションのアイデア

Expression and interaction idea

本命サンプル `Interactive Segmenter Stroke Arbitrator` は、canvas 上の合成物体に positive / negative / box / lasso を重ね、negative weight、threshold、soft edge を動かすとマスク範囲が変わります。派生の `Stroke Replay Compressor` は、pointermove の生点列と圧縮後点列を並べ、spacing と corner keep を調整しながら payload 削減率と replay しやすさを見ます。

The main sample, `Interactive Segmenter Stroke Arbitrator`, layers positive / negative / box / lasso instructions on synthetic canvas objects and updates the mask as negative weight, threshold, and soft edge change. The derivative, `Stroke Replay Compressor`, compares raw pointermove streams with compressed point streams and exposes payload reduction and replay behavior as spacing and corner retention change.

制作に使えそうな技術メモ

Production note

実モデル接続時は `@mediapipe/tasks-vision` と WASM path、interactive segmentation model URL を pin し、main thread は pointer capture と overlay 描画に寄せます。stroke は `{ brushMode, point, isCompleted }` の配列として request id と一緒に worker へ渡し、返却時に現在の request id と違う mask は描画しません。前回の mask bitmap を持つ場合は新しい mask を描く前に close し、pointermove は spacing / corner 条件で間引いてから送ると replay と保存が軽くなります。

When connecting the real model, pin `@mediapipe/tasks-vision`, the WASM path, and the interactive segmentation model URL, and keep pointer capture plus overlay rendering on the main thread. Send strokes as `{ brushMode, point, isCompleted }` arrays with a request ID to a worker, and ignore returned masks whose request ID no longer matches. If a previous mask bitmap exists, close it before drawing a new mask. Compress pointermove streams by spacing and corner rules before sending them to keep replay and persistence lightweight.

試すならこれ

If you try one thing

`Interactive Segmenter Stroke Arbitrator` で Seed strokes を押し、Negative weight を 90%、Mask threshold を 60% 以上にすると、除外 stroke が target と distractor の境界をどう削るかが見えます。派生サンプルでは Point spacing を 26px、Corner keep を 30deg 付近にすると、曲がり角を残しつつ payload を大きく削れる境界が見えます。

In `Interactive Segmenter Stroke Arbitrator`, press Seed strokes and raise Negative weight to 90% and Mask threshold above 60% to see how exclusion strokes carve the boundary between target and distractor. In the derivative sample, set Point spacing near 26 px and Corner keep near 30 degrees to find the boundary where payload drops while corners remain recognizable.
