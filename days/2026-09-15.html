注目事例と何が面白いか

Notable example and why it matters

今日の注目は、Face Landmarker を face mesh の可視化だけで終わらせず、blendshape と facial transformation matrix を UI / avatar runtime の安定した入力へ変換することです。公式 guide は face landmarks、blendshape scores、transformation matrices を同じ task の出力として示しており、表情係数と頭部姿勢を同じ frame budget で扱える点が面白いです。モデルの出力をそのまま使うより、smoothing、hysteresis、deadband、dwell を通すことで、誤発火しにくい表情 command layer にできます。

Today's notable angle is not stopping at face-mesh visualization, but converting Face Landmarker blendshapes and facial transformation matrices into stable inputs for UI / avatar runtimes. The official guide lists face landmarks, blendshape scores, and transformation matrices as outputs from the same task, which is interesting because expression coefficients and head pose can share one frame budget. Rather than using model output directly, smoothing, hysteresis, deadbands, and dwell can form an expression command layer that avoids false triggers.

表現・インタラクションのアイデア

Expression and interaction idea

本命サンプル `Face Blendshape Avatar Mixer` は、mouthSmile、browInnerUp、jawOpen、eyeBlink を synthetic stream として動かし、happy / surprised / blink の状態にまとめて command を発火します。派生の `Face Matrix Stability Probe` は、facial transformation matrix を想定した yaw / pitch / roll / translation を raw と stabilized で並べ、AR filter や avatar head bone に渡す前の揺れを観察します。

The main sample, `Face Blendshape Avatar Mixer`, animates mouthSmile, browInnerUp, jawOpen, and eyeBlink as a synthetic stream, collapsing them into happy / surprised / blink states before firing commands. The derivative, `Face Matrix Stability Probe`, places raw and stabilized yaw / pitch / roll / translation side by side for a facial-transformation-matrix-like stream, making head-pose jitter visible before it drives an AR filter or avatar head bone.

制作に使えそうな技術メモ

Production note

実装時は `FilesetResolver.forVisionTasks()`、`FaceLandmarker.createFromOptions()`、`runningMode: "VIDEO"`、`outputFaceBlendshapes: true`、`outputFacialTransformationMatrixes: true` を初期化ログに残します。video loop では timestamp 重複を避け、`detectForVideo()` の同期 block を worker 化するか cadence 制御します。blendshape は threshold だけでなく smoothing と dwell を通して command に変換し、matrix は deadband と anchor 補正を挟んで overlay や avatar bone に渡すと安定します。

For implementation, log initialization around `FilesetResolver.forVisionTasks()`, `FaceLandmarker.createFromOptions()`, `runningMode: "VIDEO"`, `outputFaceBlendshapes: true`, and `outputFacialTransformationMatrixes: true`. The video loop should avoid duplicate timestamps and move synchronous `detectForVideo()` work to a worker or cadence gate. Blendshapes should become commands through smoothing and dwell, not thresholds alone; matrices should pass through deadband and anchor correction before reaching overlays or avatar bones.

試すならこれ

If you try one thing

In `Face Blendshape Avatar Mixer`, press `Laugh pulse` and `Surprise pulse`, then adjust smoothing and the expression gate to find where commands become too eager or too delayed. In the derivative sample, press `Snap turn` and `Jitter burst` to see the face-matrix tradeoff: raising the deadband removes jitter but makes tracking feel slower.
