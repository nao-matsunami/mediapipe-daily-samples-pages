注目事例と何が面白いか

Notable example and why it matters

今日の注目は、複数の MediaPipe Task を同じカメラ体験に載せる時、推論レーンを選ぶだけでは足りず、結果を UI 操作に変換する直前で信頼度・鮮度・同意状態を合成する必要がある点です。Gesture / Hand / Holistic の公式 guide は video timestamp、presence、tracking、多出力を扱うため、サンプルでは実モデル読み込みではなく action gate の設計だけを小さく可視化しました。

Today's notable point is that when multiple MediaPipe Tasks share one camera experience, lane selection is not enough; confidence, freshness, and consent need to be fused right before results become UI actions. The official Gesture / Hand / Holistic guides involve video timestamps, presence, tracking, and multi-output results, so these samples isolate action-gate design instead of loading real models.

表現・インタラクションのアイデア

Expression and interaction idea

本命の `Multisignal Confidence Fusion Mixer` は intent preset、fire threshold、fresh window、sensor noise を動かし、Hand / Face / Pose / Object の信号が fire / review / hold / block に変わる様子を見ます。派生の `Confidence Event Quarantine Router` は review band、TTL、event rate、policy を動かし、低信頼イベントをそのまま操作にせず隔離する流れを確認します。

The main sample, `Multisignal Confidence Fusion Mixer`, lets intent preset, fire threshold, fresh window, and sensor noise change whether Hand / Face / Pose / Object signals become fire / review / hold / block. The derivative, `Confidence Event Quarantine Router`, uses review band, TTL, event rate, and policy to quarantine low-confidence events before they become direct actions.

制作に使えそうな技術メモ

Production note

実装では Task の生結果を直接イベントに変えず、`source`, `confidence`, `timestamp`, `maxAge`, `consent`, `route` を持つ中間イベントへ変換します。Hand の presence / tracking、Face の blendshape score、Pose の visibility、Object の category score は同じ尺度ではないため、preset ごとに重みを分け、古い結果には freshness decay をかけるのが扱いやすいです。

In production, do not convert raw task results directly into events; first map them into intermediate events with `source`, `confidence`, `timestamp`, `maxAge`, `consent`, and `route`. Hand presence / tracking, Face blendshape scores, Pose visibility, and Object category scores are not the same scale, so preset-specific weights and freshness decay make the system easier to reason about.

Today's mini prototype candidate

採用した本命は `Multisignal Confidence Fusion Mixer` です。実際に動く部分は synthetic な Hand / Face / Pose / Object 信号を confidence と timestamp 付きで更新し、preset weight、freshness decay、threshold で fire / review / hold / block を判定するところです。次に足すなら実 `recognizeForVideo()` / `detectForVideo()` / Holistic result、Task ごとの confidence 正規化、ユーザー別 preset 保存を追加します。派生試作は `Confidence Event Quarantine Router` で、実際に動く部分は event confidence、TTL、review band から send / review / hold / drop を振り分けるところです。次に足すなら誤操作ログ、Long Task API、古い overlay のクリック抑制、Web Audio の注意音を追加します。

Next additions should include real `recognizeForVideo()` / `detectForVideo()` / Holistic results, per-task confidence normalization, and per-user preset storage. The derivative prototype is `Confidence Event Quarantine Router`; the working pieces route event confidence, TTL, and review band into send / review / hold / drop.
