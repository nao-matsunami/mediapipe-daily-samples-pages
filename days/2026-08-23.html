Image Segmenter の callback mask をコピーして使うマット検査台

A matte inspection bench that copies Image Segmenter callback masks

Google AI Edge の Image Segmenter overview / Web guide、tasks-vision API、ImageSegmenter class / options、公式 MediaPipe Tasks demo repository を参考に、Image Segmenter の category mask を callback 内で `Uint8Array` にコピーし、その後の合成・検査 UI で使う自作サンプルを追加しました。さらに派生試作として、コピー済み mask を ROI 判定や次フレーム制御に使う発展案を合成 mask で即時検証できる小さな sandbox も追加しました。

注目事例と何が面白いか

Notable example and why it matters

今日の注目は Image Segmenter の結果そのものではなく、callback から返る mask をアプリ側の安全な状態へ移す瞬間です。公式 Web guide は Image Segmenter の作成と `segment()` / `segmentForVideo()` の実行を示し、API reference は callback の mask データを後で使うならコピーが必要だと読み取れる注意を置いています。自作サンプルでは category mask を callback 内で `Uint8Array` にコピーし、コピー後の bytes だけでマット合成、coverage、run history を描画します。

Today's notable point is not the Image Segmenter result itself, but the moment when callback-owned mask data becomes safe application state. The official Web guide shows task creation and `segment()` / `segmentForVideo()`, while the API reference implies that data needed later should be copied from the callback. The original sample copies the category mask into a `Uint8Array` inside the callback and uses only those bytes for matte compositing, coverage, and run history.

表現・インタラクションのアイデア

Expression and interaction idea

本命サンプルは、生成済みの簡易キャンバスまたはアップロード画像を Image Segmenter に渡し、CPU / GPU delegate、初期化時間、segment 時間、mask copy 時間、foreground coverage を表示します。コピー済み mask に対して overlay opacity、edge feather、backdrop hue を動かせるため、推論後の演出調整だけを独立して試せます。派生サンプルは合成 confidence field 上で ROI をドラッグし、threshold、ROI width、edge softness、alert line から「raise cue / track / ignore」を出す小さな判定器です。

The main sample sends either a seeded canvas or uploaded image to Image Segmenter and shows CPU/GPU delegate, initialization time, segment time, mask copy time, and foreground coverage. Overlay opacity, edge feather, and backdrop hue operate on the copied mask, so post-inference treatment can be tuned independently. The derivative sample lets the user drag an ROI over a synthetic confidence field and uses threshold, ROI width, edge softness, and an alert line to decide between raise cue, track, and ignore.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積できるデータは、delegate、初期化時間、segment 時間、mask copy 時間、mask 解像度、foreground coverage、overlay 設定、ROI fill、threshold、alert decision です。これを IndexedDB に保存すると、Image Segmenter の後段処理だけを日別・端末別に比較できます。Face Detector や Pose Landmarker を重ねれば人物矩形や姿勢と mask coverage のズレを見られ、Web Audio と組み合わせれば ROI fill が閾値を越えた時だけ cue 音を鳴らせます。LiteRT.js の custom model と並べる場合は、同じ ROI 判定 UI に別 runtime の mask を差し替える比較ができます。

The samples can accumulate delegate, initialization time, segment time, mask copy time, mask resolution, foreground coverage, overlay settings, ROI fill, threshold, and alert decisions. Saved to IndexedDB, this enables comparison of Image Segmenter post-processing by day and device. Combined with Face Detector or Pose Landmarker, it can reveal mismatch between person boxes or pose and mask coverage. With Web Audio, ROI fill can trigger cues only when it crosses a threshold. For LiteRT.js custom models, the same ROI UI can compare masks from a different runtime.

制作に使えそうな技術メモ

Production note

静的 HTML では `@mediapipe/tasks-vision@0.10.22/+esm` を dynamic import し、WASM path も同じ version に固定しました。モデルは公式 storage の `selfie_segmenter.tflite` を参照し、`outputCategoryMask: true`、`outputConfidenceMasks: false` で category mask のコピーに集中しています。`segment()` は同期的に UI thread を止めるので、長い動画処理に進める前に Worker / OffscreenCanvas / frame skip の設計が必要です。callback 内では `mask.getAsUint8Array()` の戻りを新しい `Uint8Array` にコピーしてから描画側へ渡します。

The static HTML dynamically imports `@mediapipe/tasks-vision@0.10.22/+esm` and pins the matching WASM path. It references the official storage `selfie_segmenter.tflite` model and focuses on category-mask copying with `outputCategoryMask: true` and `outputConfidenceMasks: false`. Because `segment()` blocks the UI thread synchronously, longer video work needs Worker, OffscreenCanvas, and frame-skip design. Inside the callback, the value from `mask.getAsUint8Array()` is copied into a new `Uint8Array` before being handed to the renderer.

今日のミニ試作候補

Today's mini prototype candidate

採用した本命は `Image Segmenter Mask Copy Studio` です。実際に動く部分は、Tasks Vision の dynamic import、`FilesetResolver.forVisionTasks()`、公式 selfie segmenter model のロード、`ImageSegmenter.segment()`、callback 内 category mask copy、coverage 表示、matte overlay 調整です。次に足すなら、confidence masks、Worker 内 `segmentForVideo()`、IndexedDB への mask 履歴、hair / multiclass model preset、Face Detector との矩形整合チェックを追加します。派生試作は `Mask ROI Threshold Sandbox` で、合成 mask 上の ROI 判定、threshold、alert line、次フレーム cue の発想を短時間で試せます。

The selected main prototype is `Image Segmenter Mask Copy Studio`. The working pieces are Tasks Vision dynamic import, `FilesetResolver.forVisionTasks()`, loading the official selfie segmenter model, `ImageSegmenter.segment()`, in-callback category mask copy, coverage display, and matte overlay tuning. Next additions should include confidence masks, Worker-side `segmentForVideo()`, IndexedDB mask history, hair and multiclass model presets, and alignment checks with Face Detector boxes. The derivative prototype is `Mask ROI Threshold Sandbox`, which quickly tests ROI decisions, thresholding, alert lines, and next-frame cue ideas on a synthetic mask.
