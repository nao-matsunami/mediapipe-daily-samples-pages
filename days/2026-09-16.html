注目事例と何が面白いか

Notable example and why it matters

今日の注目は、Image Segmenter を単なる背景ぼかしデモではなく、長時間 video loop の runtime として扱うことです。公式 guide は category mask と confidence masks を分けて説明し、さらに `segment()` / `segmentForVideo()` が同期的に UI thread を block し得ると明記しています。ここに GitHub issues で見える GPU delegate、WebGL format、MPMask close、Worker postMessage の論点を重ねると、推論精度より先に、delegate preflight、mask lifecycle、backpressure が制作上の要点になります。

Today's notable angle is treating Image Segmenter not as a background-blur demo, but as a long-running video-loop runtime. The official guide separates category masks and confidence masks, and explicitly notes that `segment()` / `segmentForVideo()` may synchronously block the UI thread. Combined with GitHub issue themes around GPU delegates, WebGL formats, MPMask close, and Worker postMessage boundaries, the production focus becomes delegate preflight, mask lifecycle, and backpressure before model accuracy.

表現・インタラクションのアイデア

Expression and interaction idea

本命サンプル `Image Segmenter Delegate Watchdog` は、GPU / CPU delegate、mask output、mask size、GPU pressure、close discipline を触ると、fallback と retained masks がどう変わるかを可視化します。派生の `Mask Backpressure Scheduler` は、camera FPS、segment interval、worker cost、queue capacity、transfer cost を分け、latest wins と quality queue のどちらが触感に合うかを比較します。

The main sample, `Image Segmenter Delegate Watchdog`, lets you adjust GPU / CPU delegate choice, mask output, mask size, GPU pressure, and close discipline to see fallback and retained masks change. The derivative, `Mask Backpressure Scheduler`, separates camera FPS, segment interval, worker cost, queue capacity, and transfer cost so you can compare latest-wins behavior against a quality-preserving queue.

制作に使えそうな技術メモ

Production note

実装では `FilesetResolver.forVisionTasks()`、`ImageSegmenter.createFromOptions()`、`baseOptions.delegate`、`outputCategoryMask`、`outputConfidenceMasks`、`runningMode: "VIDEO"`、`segmentForVideo()` の初期化と実測を分けてログします。GPU を要求する前に WebGL2、float / half-float render target、対象ブラウザを probe し、弱い場合は CPU fallback を明示します。confidence mask は描画用、category mask は index / policy 用として保持期間を分け、描画後に close する責務を worker boundary に置くと事故が減ります。

For implementation, log initialization and measurement separately around `FilesetResolver.forVisionTasks()`, `ImageSegmenter.createFromOptions()`, `baseOptions.delegate`, `outputCategoryMask`, `outputConfidenceMasks`, `runningMode: "VIDEO"`, and `segmentForVideo()`. Before requesting GPU, probe WebGL2, float / half-float render targets, and the browser; explicitly choose CPU fallback when weak. Treat confidence masks as drawing payloads and category masks as index / policy payloads, and put close responsibility at the worker boundary after drawing.
