注目事例と何が面白いか

Notable example and why it matters

今日の注目は、Hand Landmarker を「手の骨格を描くデモ」ではなく、detector fallback と tracking reuse の設計対象として見ることです。公式 Web guide は `detect()` / `detectForVideo()` の同期実行と Worker の必要性を明示し、overview は 21個の image landmarks と world landmarks、handedness を出力として整理しています。本命サンプルでは、合成ランドマーク列に detection confidence、presence confidence、tracking confidence、detector cost、UI frame budget を重ね、どのフレームで detector を再実行するか、どのフレームで tracking を再利用するかを小さく可視化しました。

Today's notable angle is treating Hand Landmarker not as a skeleton drawing demo, but as a design surface for detector fallback and tracking reuse. The official Web guide makes the synchronous nature of `detect()` / `detectForVideo()` and the need for Workers explicit, while the overview organizes 21 image landmarks, world landmarks, and handedness as outputs. The main sample overlays detection confidence, presence confidence, tracking confidence, detector cost, and UI frame budget on a synthetic landmark sequence to show which frames rerun detection and which frames reuse tracking.

表現・インタラクションのアイデア

Expression and interaction idea

本命サンプルは、手の動き、presence、IoU、detector / tracking の切り替え、推定コストを同じ画面で見せます。閾値を上げると検出が落ちやすくなり、tracking confidence を上げると動きの速い手で detector refresh が増える構図です。派生サンプルは、次に足すなら必要になる landmark feature layer を先に切り出しました。親指と人差し指の距離、親指と小指の spread、手首と中指根元の tilt、hold frames を使って `SCRUB`、`EXPAND`、`CONFIRM`、`HOLD` に変換します。

The main sample shows hand motion, presence, IoU, detector / tracking switching, and estimated cost in the same view. Raising thresholds makes detections easier to drop, and raising tracking confidence causes more detector refreshes on fast hands. The derivative sample isolates the landmark feature layer that would be useful next. It maps thumb-index distance, thumb-pinky spread, wrist-to-middle-base tilt, and hold frames into `SCRUB`, `EXPAND`, `CONFIRM`, and `HOLD`.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積できるデータは、frame index、numHands、presence confidence、detection confidence、tracking IoU、detector refresh flag、estimated inference cost、21点 image landmarks、pinch distance、spread distance、tilt、hold history、stable command です。Gesture Recognizer と合わせれば既存 gesture label の前後に独自 feature gate を追加できます。Face Landmarker や Pose Landmarker と合わせると、手が顔や肩に近づいた時だけ UI を出すような空間的な条件を作れます。Web Audio と組み合わせれば pinch で scrubbing、spread で filter width、tilt で confirm といった連続入力にも展開できます。

The samples can accumulate frame index, numHands, presence confidence, detection confidence, tracking IoU, detector refresh flags, estimated inference cost, 21 image landmarks, pinch distance, spread distance, tilt, hold history, and stable commands. Combined with Gesture Recognizer, custom feature gates can wrap existing gesture labels. Combined with Face Landmarker or Pose Landmarker, spatial conditions can show UI only when a hand approaches the face or shoulder. With Web Audio, pinch can scrub, spread can control filter width, and tilt can confirm continuous input.

制作に使えそうな技術メモ

Production note

静的HTMLでは `@mediapipe/tasks-vision@0.10.22/+esm` と同 version の WASM path を dynamic import し、公式 README と公式サンプルにある `hand_landmarker.task` の model URL を使う構成にしました。モデル取得に失敗しても、同じ閾値と同じ UI で合成ランドマークを動かせる synthetic fallback を残しています。実際の camera loop では `detectForVideo()` の同期ブロックを避けるため、公式サンプルの worker 実装のように Worker 側で task instance と option update を持つ構成が良さそうです。

The static HTML dynamically imports `@mediapipe/tasks-vision@0.10.22/+esm` and the matching WASM path, using the `hand_landmarker.task` model URL shown in the official README and sample implementation. If model loading fails, the same thresholds and UI still drive a synthetic fallback. For a real camera loop, the synchronous blocking of `detectForVideo()` suggests keeping the task instance and option updates inside a Worker, as in the official sample worker.

試すならこれ

If you try one thing

まず `Hand Landmark Tracking Budget Lab` を開き、`Run timeline` を押して synthetic のまま動かします。`Fast wave` preset にして tracking confidence を上げると detector refresh が増え、detector cost を UI budget より大きくすると over budget 表示が出ます。モデル取得が通る環境では `Load Task` を押して、同じ閾値を実 Task 初期化にも渡せます。派生の `Hand Feature Command Mixer` では `Pinch scrub` と `Mixed handoff` を切り替え、hold frames を増やすとコマンドが安定する代わりに反応が遅れることを確認できます。

First open `Hand Landmark Tracking Budget Lab`, press `Run timeline`, and keep it synthetic. Switch to the `Fast wave` preset and raise tracking confidence to increase detector refreshes; raise detector cost above the UI budget to see over-budget states. When model loading works, press `Load Task` to pass the same thresholds into a real Task initialization. In the derivative `Hand Feature Command Mixer`, switch between `Pinch scrub` and `Mixed handoff`; increasing hold frames stabilizes commands while making the response slower.

俯瞰メモ

Bird's-eye memo

8月後半の試作は、Face Detector の ROI gate、Gesture Recognizer の command router、Interactive Segmenter の prompt UI など、Task の出力を後段の判断へ変換する方向に進んでいます。Hand Landmarker は検出結果そのものよりも、tracking をいつ信用するか、ランドマークをどの feature に変換するかがプロダクト差になりやすい領域です。今日の2本は、推論と UI の時間予算、そしてランドマークからコマンドへの feature layer を分けて確認できるようにしました。

The late-August samples are moving toward converting Task outputs into downstream decisions: Face Detector ROI gates, Gesture Recognizer command routers, and Interactive Segmenter prompt UIs. For Hand Landmarker, product behavior often depends less on drawing detections and more on when tracking should be trusted and which features landmarks become. Today's two samples separate inference / UI time budget from the feature layer that turns landmarks into commands.
