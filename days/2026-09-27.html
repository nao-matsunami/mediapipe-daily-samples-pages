注目事例と何が面白いか

Notable example and why it matters

今日の注目は Image Embedder の embedding を単なる類似度検索に使う前に、`l2_normalize` と `quantize` の判定差を UI で校正することです。公式 API は cosine similarity と running mode を提供しますが、実アプリでは gate 付近で float と quantized の route が変わると、cache reuse、再 embed、human review の体験が揺れます。そこで本命サンプルは実モデルを呼ばず、synthetic embedding で float / quantized の差分を触れるようにしました。

Today's notable angle is calibrating `l2_normalize` and `quantize` decisions in the UI before using Image Embedder embeddings for similarity search. The official API provides cosine similarity and running modes, but in real apps a route change near the gate can affect cache reuse, re-embedding, and human review. The main sample therefore avoids a real model and makes float / quantized differences touchable with synthetic embeddings.

Expression and interaction idea

本命サンプル `Image Embedder Quantization Calibrator` は、preset、quantize strength、input noise、similarity gate、ROI drift、L2 toggle を動かし、float cosine と quantized cosine、差分、route flip を表示します。派生の `Embedding Threshold Drift Sentinel` は、reuse gate、review band、age penalty、drift speed を操作し、保存済み embedding を reuse / review / re-embed に振り分けます。

The main sample, `Image Embedder Quantization Calibrator`, exposes preset, quantize strength, input noise, similarity gate, ROI drift, and an L2 toggle while showing float cosine, quantized cosine, deltas, and route flips. The derivative, `Embedding Threshold Drift Sentinel`, adjusts reuse gate, review band, age penalty, and drift speed to route saved embeddings into reuse / review / re-embed.

制作に使えそうな技術メモ

Production note

実接続時は model adapter が返す embedding の型、正規化済みかどうか、量子化の有無、元画像 / ROI / timestamp を job metadata として保存します。`embedForVideo` 風の処理では timestamp の単調増加、古い結果の破棄、同期コストの worker 隔離を分けます。gate は1本だけにせず、reuse gate と review floor を分け、量子化で route が変わった時だけ監査ログに残すと運用しやすくなります。

When wiring a real model, save the embedding type, whether it is normalized, quantization state, source image / ROI / timestamp as job metadata. For `embedForVideo`-style processing, keep monotonic timestamps, stale-result rejection, and synchronous-cost worker isolation separate. Use a reuse gate plus a review floor instead of one threshold, and log only cases where quantization changes the route.
