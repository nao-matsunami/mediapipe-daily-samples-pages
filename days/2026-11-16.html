表現・インタラクションのアイデア

Expression and interaction idea

本命は WASM取得、コンパイル、モデル取得、準備完了を一つのオーケストラとして段階表示します。派生は人物の左右、画面上の左右、モデルラベルを別行で固定表示します。これにより、読み込み失敗時は再試行対象を、ジェスチャー時は発火先を、利用者が推測せず確認できます。

Show startup phases explicitly, and keep person, screen, and model handedness legible as separate states.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

開始時刻、各フェーズの所要時間、失敗種別、反転設定、handedness、最終アクションを映像なしで蓄積すれば、端末・ネットワーク別の離脱点や左右誤操作を分析できます。Performance API、IndexedDB の上限付きログ、Hand Landmarker のランドマーク、WebHID/音フィードバックと組み合わせると、環境適応型の入力体験へ発展します。

Privacy-preserving phase timings and handedness events can reveal startup friction and side mistakes without retaining video.

制作に使えそうな技術メモ

Production note

実装では FilesetResolver とモデル取得を一括スピナーにせず、ネットワーク、WASM初期化、モデル、カメラ許可を状態機械に分けます。失敗時は再試行してよい層を明示します。handedness は model output を直接UIへ渡さず、mirror/selfie設定を通す変換関数を一箇所に置き、画面座標と人物基準の意味をテストします。

Use a startup state machine and a single tested transform between model output, mirrored view, and action coordinates.

俯瞰メモ

Bird's-eye memo

Web MLの信頼性はモデル精度だけで決まりません。待ち時間が何を意味するか、画面に見える手がどの座標系で解釈されるかを先に説明可能にすると、モデル・端末・回線が変わっても体験の筋が通ります。

Explainable waiting and coordinate systems make Web ML resilient to model, device, and network changes.
