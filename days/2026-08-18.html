Object Detector の bbox をゾーン滞在タイマーにする

Turn Object Detector boxes into a zone dwell timer

Google AI Edge の Object Detector Web guide、ObjectDetector JavaScript API、tasks-vision package、公式 samples web を参考に、検出 bbox を単に描画するのではなく、監視ゾーンへの侵入、滞在秒数、HOLD 判定へ変換する自作最小サンプルを追加しました。カメラと公式モデルが使える場合は `detectForVideo()` を使い、使えない場合も合成検出ストリームで同じ dwell gate を検証できます。

注目事例と何が面白いか

Notable example and why it matters

今日の注目は Object Detector の bbox を、表示用の矩形ではなく「画面のどこに、どれだけ長く存在したか」という状態に変換することです。公式デモは検出カテゴリと bbox を確認する入口として便利ですが、自作サンプルでは中央の watch zone と bbox の重なりを見て、object ごとの滞在秒数を積算し、しきい値を超えたら HOLD として記録します。店舗棚、作業台、展示、カメラ UI のような場面では、検出そのものより dwell event の方がアプリに接続しやすいです。

Today's notable angle is converting Object Detector bounding boxes from display rectangles into state: where an object is and how long it stayed there. The official demo is useful for checking categories and boxes, while this original sample watches overlap with a central zone, accumulates per-object dwell seconds, and records HOLD when the threshold is crossed. For shelves, workbenches, exhibits, or camera UIs, dwell events are often easier to connect to an app than raw detections.

表現・インタラクションのアイデア

Expression and interaction idea

UI は camera / synthetic stream、watch zone、score threshold、dwell alert sec、per-object timer、run log に分けました。Demo stream では person、cup、chair の合成 bbox が動き、ゾーンに入るとタイマーが増え、外れると減衰します。Load model と Start camera が成功した環境では、公式 EfficientDet Lite0 モデルの `detectForVideo()` 結果を同じ dwell gate に流し込めます。

The UI is split into camera / synthetic stream, watch zone, score threshold, dwell alert seconds, per-object timer, and run log. In Demo stream, synthetic person, cup, and chair boxes move through the zone; timers rise while inside and decay when outside. When Load model and Start camera succeed, the official EfficientDet Lite0 `detectForVideo()` results feed into the same dwell gate.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積できるデータは runtime、score threshold、zone width、alert 秒数、category、score、bbox、zone overlap、per-object dwell seconds、HOLD 発火時刻、モデル読み込み失敗、カメラ拒否ログです。Image Embedder と組み合わせると同じ category 内の見た目の差分を取れます。Gesture Recognizer と組み合わせると手ジェスチャーで watch zone を切り替えられ、Web Audio では滞在時間に応じた音フィードバック、IndexedDB では dwell event のローカル履歴保存へ発展できます。

The sample can accumulate runtime, score threshold, zone width, alert seconds, category, score, box, zone overlap, per-object dwell seconds, HOLD timestamps, model-load failure, and camera-denial logs. Combined with Image Embedder, it could compare appearance within a category. Gesture Recognizer could switch watch zones with hand gestures, Web Audio could provide dwell-based sound feedback, and IndexedDB could store local dwell-event history.

制作に使えそうな技術メモ

Production note

`@mediapipe/tasks-vision@0.10.35` の `vision_bundle.mjs` を動的 import し、`FilesetResolver.forVisionTasks()` で WASM を解決してから、`ObjectDetector.createFromOptions()` に公式 EfficientDet Lite0 モデル URL、`runningMode: "VIDEO"`、`maxResults`、`scoreThreshold` を渡します。動画では `detectForVideo(video, timestamp)` を使います。今日の独自部分は、bbox を `zoneRect` と交差判定し、zone 内では dwell を加算、外では減衰させ、連続検出のちらつきで即リセットされないようにした点です。

The sample dynamically imports `vision_bundle.mjs` from `@mediapipe/tasks-vision@0.10.35`, resolves WASM with `FilesetResolver.forVisionTasks()`, and passes the official EfficientDet Lite0 model URL, `runningMode: "VIDEO"`, `maxResults`, and `scoreThreshold` to `ObjectDetector.createFromOptions()`. Video uses `detectForVideo(video, timestamp)`. The original part intersects boxes with `zoneRect`, increments dwell while inside, decays it while outside, and avoids instant resets from detection flicker.
