今日の重要トピック

  1. Hand Landmarker Web guide は 21 hand landmarks、world landmarks、handedness を返すことを示しており、x/y は画像幅と高さで [0,1] に正規化され、z は wrist を原点に x と近いスケールで扱われる。

    The Hand Landmarker Web guide shows that the task returns 21 hand landmarks, world landmarks, and handedness; x/y are normalized by image width and height, while z uses the wrist as origin and a scale roughly comparable to x.

  2. Hand Landmarker の `detect()` / `detectForVideo()` は同期処理で UI thread を block し得るため、座標描画より前に cadence、busy flag、worker 境界を設計しておく必要がある。

    `detect()` and `detectForVideo()` for Hand Landmarker are synchronous and can block the UI thread, so cadence, busy flags, and worker boundaries should be planned before landmark drawing.

  3. presence confidence と tracking confidence はモデル設定だけでなく、UI を更新するか、前回 pose を短時間維持するかを決める gate として使える。

    Presence confidence and tracking confidence are not only model settings; they can gate whether the UI updates or briefly holds the previous pose.

  4. NormalizedRect は center、width、height、clockwise rotation を normalized image coordinates で持つため、mirrored preview や CSS contain / cover の変換を忘れると overlay が大きくズレる。

    NormalizedRect stores center, width, height, and clockwise rotation in normalized image coordinates, so mirrored previews and CSS contain / cover projection can move overlays far from the target if skipped.

  5. MediaPipe v1.0.0 release notes では running mode enum の標準化や VisionTaskRunner の running mode cache、JS bundle 周りの更新があり、Web sample でも setup と runtime の境界を明示したい。

    MediaPipe v1.0.0 release notes mention standardized running mode enum constants, cached running mode in VisionTaskRunner, and JS bundle updates, making setup/runtime separation useful in Web samples.

注目事例と何が面白いか

Notable example and why it matters

今日の注目は Hand Landmarker の出力を「点の配列」ではなく「座標系の契約」として扱うことです。公式 guide は 21 個の landmarks、world landmarks、handedness、presence / tracking confidence を説明しており、ここから UI 側では mirrored camera、center crop、z-depth、前回 pose の保持を考える必要があります。面白いのは、モデルを変えなくても座標変換と confidence gate だけで、操作 UI の体感安定性が大きく変わる点です。

Today's notable point is treating Hand Landmarker output not as a list of dots but as a coordinate contract. The official guide describes 21 landmarks, world landmarks, handedness, and presence / tracking confidence; on the UI side this means planning mirrored cameras, center crops, z-depth, and holding the previous pose. The interesting part is that coordinate projection and confidence gates can change perceived interaction stability even without changing the model.

表現・インタラクションのアイデア

Expression and interaction idea

本命サンプル `Hand Landmark Coordinate Calibrator` は、合成 21 点ランドマークを normalized x/y から canvas pixel へ変換し、z-depth を色とサイズに変え、presence / tracking gate が落ちた時は UI 更新を止める判断を表示します。派生の `ROI Rect Mirror Letterbox Probe` は NormalizedRect と keypoint を mirrored preview、contain / cover、source aspect ratio に通し、正しい投影と変換忘れのズレを同時に見せます。

The main sample, `Hand Landmark Coordinate Calibrator`, converts synthetic 21-point landmarks from normalized x/y into canvas pixels, maps z-depth into color and size, and shows when presence / tracking gates should pause UI updates. The derivative, `ROI Rect Mirror Letterbox Probe`, runs a NormalizedRect plus keypoints through mirrored preview, contain / cover, and source aspect ratio, showing the correct projection next to the drift from missed transforms.

Combined with Hand Landmarker, Gesture Recognizer, Face Landmarker, Pose Landmarker, WebGL overlays, WebXR hand rays, Pointer Events, IndexedDB, or LLM operation summaries, this becomes a small calibration panel for turning hand shape into stable UI commands or spatial controls.

制作に使えそうな技術メモ

Production note

実装に進める時は、`FilesetResolver.forVisionTasks(basePath)`、`HandLandmarker.createFromOptions()`、`runningMode: "VIDEO"`、`numHands`、`minHandDetectionConfidence`、`minHandPresenceConfidence`、`minTrackingConfidence` を setup log に分けます。描画側では normalized x/y を source image の座標として受け取り、CSS の mirror、object-fit、letterbox offset、devicePixelRatio を必ず通してから overlay に変換します。`detectForVideo()` の同期 block は worker 化または cadence 制御で吸収します。

For production, split setup logging across `FilesetResolver.forVisionTasks(basePath)`, `HandLandmarker.createFromOptions()`, `runningMode: "VIDEO"`, `numHands`, `minHandDetectionConfidence`, `minHandPresenceConfidence`, and `minTrackingConfidence`. On the rendering side, treat normalized x/y as source-image coordinates, then apply CSS mirror, object-fit, letterbox offset, and devicePixelRatio before overlay projection. Synchronous `detectForVideo()` blocking should be absorbed with workers or cadence control.
