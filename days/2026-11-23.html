表現・インタラクションのアイデア

Expression and interaction idea

本命は確信度・鮮度・静止・再発火待ちを四つのバッジにし、すべて通るとだけ操作を発火します。どの条件で保留されたかを身体的なポインタ移動と一緒に見せるので、単一thresholdより調整意図を共有しやすくなります。派生はTask、track、結果参照をスイッチボードに見立て、危険な切替で残ったhandleを可視化します。

The main exposes score, freshness, stillness, and cooldown as four action badges; the derivative makes task, track, and result ownership visible during switches.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

採用/保留の理由、category score、timestamp、指先速度、handedness、フレーム年齢、cleanup開始/完了、Task種別を小さなイベント列として残せます。Performance API、Long Tasks、IndexedDBの容量上限付きログ、Web Audioの確認音、WebHIDやXRの出力と組み合わせれば、端末別に誤発火・遅延・セッション寿命を比較できます。

Admission reasons, scores, timestamps, velocity, handedness, result age, and cleanup spans can combine with performance logs, bounded storage, audio, HID, and XR.

制作に使えそうな技術メモ

Production note

実装では認識結果を受けた時点で時刻と座標系を固定し、scoreだけで操作を確定しません。video loopでは最新の一要求だけを保持し、画面離脱・route変更・カメラ停止の共通cleanupにTaskのclose、track.stop、timer/AbortController、結果参照の解放を集約します。ミラー映像では手性が反転する契約もUIのラベルと行動マップへ反映します。

Fix result time and coordinates, keep only the newest request, centralize close/track/abort/result cleanup, and map mirrored handedness explicitly.

俯瞰メモ

Bird's-eye memo

Web MLの操作感は、モデル出力をただ早く表示することではなく、「なぜ今は発火しないのか」「画面を離れたら何が止まるのか」を説明できることから強くなります。採用と解放を小さな可視化として先に固定すれば、モデル・delegate・UIを後から交換しても、検証の軸を維持できます。

Web ML feels trustworthy when it explains why an action is held and what stops on exit. Visualizing admission and release preserves that test axis across models and UI changes.
