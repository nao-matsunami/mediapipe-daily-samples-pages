表現・インタラクションのアイデア

Expression and interaction idea

本命は開始・継続の二閾値を分け、confidence波形と出力状態の切替を同時に見せます。派生は遅い旧結果を投入してから映像源を切り替え、generation tokenで結果が破棄される様子をログで見せます。

The main probe separates enter and keep thresholds. The derivative shows a slow old result being rejected after a source switch via a generation token.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

保存するなら画像そのものではなく、frame timestamp、presence、threshold設定、状態遷移、session ID、処理時間、破棄理由を最小単位にします。MediaPipe Task結果、Performance API、Web Worker、Canvas/WebGL overlay、Web Audio、同意済みの診断基盤を組み合わせると、時間的な劣化を再現・比較できます。

Store timestamps, presence, thresholds, transitions, session IDs, latency, and drop reasons—not images. Combine Task results with Performance API, Workers, overlays, audio, and consented diagnostics.

制作に使えそうな技術メモ

Production note

単一の閾値だけでは境界付近で表示が点滅しやすいため、enter/keepと最小継続時間を別パラメータにします。video差替え、task reset、model再読込の境界ごとにsession IDを進め、非同期完了時に一致確認します。メトリクス送信は公式privacy noticeと同意要件を確認して設計します。

Use enter/keep thresholds plus a dwell time to avoid flicker. Increment a session ID for source/task/model boundaries and check it on async completion. Design metrics around the official privacy notice and consent.

俯瞰メモ

Bird's-eye memo

Web MLの体験品質は、瞬間のscoreだけでなく、いつ始め、いつ維持し、いつ古い結果を忘れるかで決まります。境界を明示すると、精度改善とUI改善を混同せずに検証できます。

Web ML quality depends on when output starts, persists, and forgets stale results—not just a score. Explicit boundaries separate UI and model experiments.

Today's mini prototype candidate

The main selected prototype controls enter/keep thresholds over synthetic presence; next add dwell time and real FaceLandmarker presence. The derivative rejects delayed old-session results; next add real video switching, Task lifecycle, and AbortController.
