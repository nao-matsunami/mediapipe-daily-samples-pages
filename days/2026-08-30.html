表現・インタラクションのアイデア

Expression and interaction idea

preflight は `Run preflight` で現在ブラウザの WebGPU / isolation / secure context を即時計測し、`@litert-lm/core` の dynamic import と model URL の HEAD probe を走らせます。`Try backend matrix` は static hosted demo、PWA / offline cache、lab experiment の3プロファイルを比較し、どの条件で WebGPU first から Hybrid / WASM first へ倒すべきかを可視化します。派生の `Prompt Stream Budget` は、実モデルを読む前に prompt token、max output、chunk size、cancel 動線を触って、ストリーミングUIの感触だけを短時間で確認します。

The preflight runs local WebGPU / isolation / secure-context checks, dynamic-imports `@litert-lm/core`, and probes the model URL with HEAD. `Try backend matrix` compares static hosted demo, PWA / offline cache, and lab experiment profiles to show when to shift from WebGPU first to Hybrid or WASM first. The derivative `Prompt Stream Budget` lets the user tune prompt tokens, max output, chunk size, and cancel behavior before loading a real model, checking the streaming UI feel quickly.

制作に使えそうな技術メモ

Production note

静的HTMLから `await import('https://cdn.jsdelivr.net/npm/@litert-lm/core@0.16.0/+esm')` を試し、`Engine` export の有無と import latency を記録します。model URL は `fetch(..., { method: 'HEAD' })` で content-length を見るだけにして、数GB級の取得や Engine 作成は行いません。WebGPU は `navigator.gpu`、isolation は `crossOriginIsolated`、secure context は `isSecureContext` を見る構成です。実運用では explicit opt-in の `Engine.create()` smoke test、`engine.delete()` の finally cleanup、JSON export を次段に置くのがよさそうです。

The static HTML tries `await import('https://cdn.jsdelivr.net/npm/@litert-lm/core@0.16.0/+esm')`, then records whether `Engine` exists and how long the import took. The model URL check only uses `fetch(..., { method: 'HEAD' })` to inspect content-length, avoiding multi-GB downloads and Engine creation. WebGPU uses `navigator.gpu`, isolation uses `crossOriginIsolated`, and secure context uses `isSecureContext`. For production, add an explicit opt-in `Engine.create()` smoke test, `engine.delete()` in finally cleanup, and JSON export as the next layer.
