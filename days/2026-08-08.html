Text Embedder で短文の近さを可視化する

Visualize short-text proximity with Text Embedder

MediaPipe Tasks Text Embedder の `embed(text)` と cosine similarity を意識した、自作の短文類似度ボードを追加しました。3つの文章を比較し、類似度行列、ペア順位、共有語を表示します。環境が許せば Universal Sentence Encoder 版 MediaPipe Text Embedder を任意ロードし、失敗してもローカル n-gram fallback が動きます。

    MediaPipe v0.10.35 release notes include JavaScript export fixes and improved MP Task file use in Vite workers, which is a useful base for future Worker-based samples.

注目事例と何が面白いか

Notable example and why it matters

今日の注目は、Text Embedder を「テキストを数値化する API」としてだけでなく、短いメモ同士の近さを触れる UI として見せることです。公式 Web guide は Universal Sentence Encoder の `.tflite` を `TextEmbedder.createFromOptions()` に渡し、`embed(text)` で embedding を得る最小経路を示しています。今日のサンプルは3つの短文を入力にし、類似度行列、ペア順位、共有語を同時に表示して、意味ベクトルの使い道を小さく確認できます。

Today's notable angle is showing Text Embedder not just as a text-to-number API, but as a touchable UI for comparing short notes. The official Web guide shows the minimal path of passing a Universal Sentence Encoder `.tflite` model to `TextEmbedder.createFromOptions()` and calling `embed(text)`. Today's sample takes three short texts and displays a similarity matrix, pair ranking, and shared tokens so the use of semantic vectors is visible in a small form.

表現・インタラクションのアイデア

Expression and interaction idea

News、Product、Motion のプリセットを切り替え、3つの textarea を編集すると即座に比較が更新されます。Load MediaPipe を押すと CDN から `@mediapipe/tasks-text` とモデルを読み込み、成功した場合は MediaPipe の embedding を使います。ネットワークや WASM 制約で失敗しても、同じ UI がローカル n-gram fallback で動くため、公開アーカイブとして常に試せる状態を保てます。

Switch News, Product, and Motion presets, then edit the three textareas to update comparisons immediately. Pressing Load MediaPipe fetches `@mediapipe/tasks-text` and the model from the CDN, using MediaPipe embeddings when successful. If network or WASM constraints fail, the same UI keeps working with a local n-gram fallback so the public archive remains usable.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積できるデータは入力文、embedding source、ベクトル次元、pairwise cosine similarity、上位ペア、共有 token、プリセット選択です。Language Detector と組み合わせると多言語メモの分類前処理に、Text Classifier と合わせると意味的に近い文の感情やカテゴリ比較に使えます。Vision 側の Pose / Face / Hand サンプルから生成した短い説明文を Text Embedder に渡せば、動作ログや表情ログを意味検索する小さな Web ML ノートになります。

The accumulated data includes input texts, embedding source, vector dimensions, pairwise cosine similarity, top pair, shared tokens, and preset selection. Combined with Language Detector it can preprocess multilingual notes; with Text Classifier it can compare sentiment or categories among semantically similar sentences. Feeding short descriptions generated from the Pose / Face / Hand samples into Text Embedder would turn motion or expression logs into a small Web ML semantic notebook.

制作に使えそうな技術メモ

Production note

MediaPipe 経路は `@mediapipe/tasks-text@0.10.22` を CDN import し、`FilesetResolver.forTextTasks()` で WASM を解決し、`TextEmbedder.createFromOptions()` に Universal Sentence Encoder の `modelAssetPath` を渡す形にしました。API reference では `embed(text)` と `TextEmbedder.cosineSimilarity()` が明記されています。今回の fallback は128次元の hashed n-gram ベクトルで、MediaPipe の意味理解とは別物ですが、UI とデータ形の検証には十分です。

The MediaPipe path imports `@mediapipe/tasks-text@0.10.22` from a CDN, resolves WASM with `FilesetResolver.forTextTasks()`, and passes the Universal Sentence Encoder `modelAssetPath` into `TextEmbedder.createFromOptions()`. The API reference documents `embed(text)` and `TextEmbedder.cosineSimilarity()`. The fallback uses 128-dimensional hashed n-gram vectors; it is not equivalent to MediaPipe semantic understanding, but it is enough to validate the UI and data shape.
