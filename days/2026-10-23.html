表現・インタラクションのアイデア

Expression and interaction idea

本命 `Selfie Coordinate Compass` は、プレビュー鏡像と結果x反転を別スイッチにし、同じ点でも表示位置とreported resultが異なることを示します。派生 `Detector Label Provenance` はlocale、fallback、候補を切り替え、表示文字がmetadata、英語fallback、stable IDのどれに由来するかを見せます。

The main compass separates preview mirroring from reported x inversion. The derivative switches locale, fallback, and candidate to expose whether a label came from metadata, English fallback, or a stable ID.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

保存対象はcamera frameではなく、normalized landmark、表示transform、reported座標、category ID、metadata locale、fallback理由、処理時間に絞れます。MediaPipe Task結果、Canvas/WebGL overlay、Performance API、Web Worker、aria-live、CMS翻訳辞書と組み合わせると、端末内推論の来歴を検査できる制作ツールになります。

Store normalized landmarks, display transforms, reported coordinates, category IDs, metadata locale, fallback reason, and timing—not camera frames. Combine Task results with Canvas/WebGL, Performance API, Workers, aria-live, and a CMS translation dictionary.

制作に使えそうな技術メモ

Production note

CSS transformだけで鏡像にするのか、Task optionで入力座標も反転するのかを分け、source/display/reportedの3座標を命名します。ラベルはcategory IDをstable keyとし、display name、希望locale、fallback種別を分離します。公開PRは型定義・公式docs・release noteで確認できるまで採用しません。

Separate a CSS-only mirror from an input/result coordinate transform and name source/display/reported spaces. Keep category ID, display name, requested locale, and fallback type separate. Do not adopt public-PR APIs before docs, typings, and release notes confirm them.

俯瞰メモ

Bird's-eye memo

Web ML の信頼性は精度値だけでは決まりません。画面が鏡なのか、返る数値がどの座標系か、文字列がどのmetadataから来たかをUIが説明できると、統合時の事故を小さくできます。

Web ML trust is not only accuracy: UI should explain whether the screen is mirrored, which coordinate space numbers use, and where strings originated.
