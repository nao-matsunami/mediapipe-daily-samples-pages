注目事例と何が面白いか

Notable example and why it matters

今日の注目は、Image Segmenter の結果をただ塗るのではなく、category mask と confidence mask を UI 合成前の別レイヤーとして扱うことです。公式 guide は predefined categories による領域分割と、category / confidence mask の出力を説明しています。昨日の Interactive Segmenter stroke protocol は「どこを取りたいか」の入力設計でしたが、今日は「返ってきた mask をどう信用し、いつ描き、いつ捨てるか」の設計です。

Today's notable angle is treating Image Segmenter output not as a paint overlay, but as separate category-mask and confidence-mask layers before UI composition. The official guide describes segmentation by predefined categories and outputs such as category and confidence masks. Yesterday's Interactive Segmenter stroke protocol addressed how users express what they want; today focuses on how to trust, draw, and retire the returned mask.

表現・インタラクションのアイデア

Expression and interaction idea

本命サンプル `Mask Confidence Compositor` は、合成フレーム上の人物・髪・服・背景 detail を category / confidence / hybrid 表示で重ね、confidence threshold、edge feather、overlay alpha、frame budget を動かせます。派生の `Mask Bitmap Lifecycle Sentinel` は、worker から遅れて返る複数 mask を request id で並べ、古い結果の拒否、前回 bitmap の close、未 close 圧力を見ます。

The main sample, `Mask Confidence Compositor`, overlays person / hair / clothing / background-detail regions on a synthetic frame and exposes category, confidence, and hybrid views with confidence threshold, edge feather, overlay alpha, and frame budget controls. The derivative, `Mask Bitmap Lifecycle Sentinel`, lines up delayed worker-style mask returns by request ID and tracks stale-result rejection, closing the previous bitmap, and unclosed-resource pressure.

制作に使えそうな技術メモ

Production note

実モデル接続時は `@mediapipe/tasks-vision`、WASM fileset、model URL を pin し、`outputCategoryMask` と `outputConfidenceMasks` のどちらを UI が必要とするかを先に決めます。video loop では segmentForVideo の同期コストを直接 main thread に積み続けず、cadence、worker、request id、stale result rejection を入れます。ImageBitmap や mask resource は次の mask を current にする前に明示的に破棄した扱いにし、mask area と open bytes をログに残すと回帰検知しやすくなります。

When connecting the real model, pin `@mediapipe/tasks-vision`, the WASM fileset, and the model URL, then decide whether the UI needs `outputCategoryMask`, `outputConfidenceMasks`, or both. In video loops, do not keep stacking synchronous `segmentForVideo` work on the main thread; add cadence, a worker boundary, request IDs, and stale-result rejection. Treat ImageBitmap or mask resources as explicitly retired before making the next mask current, and log mask area plus open bytes for easier regression detection.
