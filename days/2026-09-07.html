注目事例と何が面白いか

Notable example and why it matters

今日の注目は Holistic Landmarker です。公式 Web guide は face、hand、pose をまとめて扱うタスクとして説明し、`outputFaceBlendshapes` と `outputPoseSegmentationMasks` を任意出力として持っています。面白いのは、1つのモデル接続で UI に出したい情報が一気に増えるため、精度 gate だけでなく、どの stream を採用し、どの optional output を描画し、フレーム予算を超えた時に何を保留するかを先に設計できる点です。

Today's notable topic is Holistic Landmarker. The official Web guide presents it as a task that combines face, hand, and pose, with `outputFaceBlendshapes` and `outputPoseSegmentationMasks` as optional outputs. The interesting part is that one model connection can produce many UI-relevant streams at once, so it is useful to design not only confidence gates, but also which streams are accepted, which optional outputs are drawn, and what is held back when the frame budget is exceeded.

表現・インタラクションのアイデア

Expression and interaction idea

本命サンプル `Holistic Output Budget Console` は、合成した人物 skeleton、顔楕円、手指線、任意の pose mask を表示し、face / pose / hand の gate、frame budget、`outputFaceBlendshapes`、`outputPoseSegmentationMasks` を動かせます。timeline は face / pose / hand / mask / drop の状態を色で分けます。派生の `Holistic Micro Command Router` は、smile、左右の hand-open、身体中心の左右 shift を `accept`、`back`、`next-panel`、`previous-panel`、`attention` のような短い UI コマンドに変換します。

The main sample, `Holistic Output Budget Console`, displays a synthetic skeleton, face oval, hand rays, and optional pose mask while exposing face/pose/hand gates, frame budget, `outputFaceBlendshapes`, and `outputPoseSegmentationMasks`. The timeline separates face, pose, hand, mask, and dropped states by color. The derivative `Holistic Micro Command Router` converts smile, left/right hand-open, and body-center shift cues into compact UI commands such as `accept`, `back`, `next-panel`, `previous-panel`, and `attention`.

制作に使えそうな技術メモ

Production note

本命 HTML は `@mediapipe/tasks-vision@1.0.1/+esm` の dynamic import preflight を持ち、`HolisticLandmarker` と `FilesetResolver` の export 確認に使えます。本番化では `FilesetResolver.forVisionTasks()`、`HolisticLandmarker.createFromOptions()`、`runningMode: "VIDEO"`、`detectForVideo(video, timestamp)` を接続します。GitHub 実装は callback で返る mask lifetime に注意を促しているため、非同期処理や Worker へ渡す場合は callback 内で copy する方針を明示する必要があります。

The main HTML includes a dynamic import preflight for `@mediapipe/tasks-vision@1.0.1/+esm`, useful for checking `HolisticLandmarker` and `FilesetResolver` exports. For production, connect `FilesetResolver.forVisionTasks()`, `HolisticLandmarker.createFromOptions()`, `runningMode: "VIDEO"`, and `detectForVideo(video, timestamp)`. The GitHub implementation warns about callback-scoped mask lifetime, so asynchronous processing or worker handoff should explicitly copy masks inside the callback.
