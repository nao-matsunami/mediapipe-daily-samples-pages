注目事例と何が面白いか

Notable example and why it matters

今日の注目は Holistic Landmarker の「複数出力が1つの task から返る」点を、UI ではなく後段の synchronization 問題として扱うことです。公式 guide は face / hand / pose をまとめて検出できること、動画では timestamp を渡して `detectForVideo` することを示しています。実アプリでは pose は十分、片手は欠損、face は少し遅れて到着、という状態が起きるので、同じ timestamp の holistic bundle をいつ emit するかを明示する必要があります。

Today's notable angle is treating Holistic Landmarker's combined outputs as a downstream synchronization problem rather than only a UI rendering problem. The official guide shows combined face / hand / pose detection and `detectForVideo` with timestamps for video. Real apps can see pose arrive confidently, one hand drop out, and face arrive slightly late, so the app needs an explicit rule for when to emit a holistic bundle for the same timestamp.

Expression and interaction idea

The main sample, `Holistic Frame Sync Console`, adjusts sync window, confidence gate, dropout, worker jitter, and hold policy while showing synthetic pose / face / left-hand / right-hand packets on an arrival timeline and skeleton. The derivative, `Holistic Signal Command Router`, adjusts dwell frames, cooldown, signal noise, presence gate, and command set while converting face focus, shoulder tilt, and hand distance into small commands.

制作に使えそうな技術メモ

Production note

実接続時は `detectForVideo(video, timestamp)` の timestamp を bundle id にし、UI draw、command routing、analytics event を同じ id で結びます。optional な face blendshapes や pose segmentation masks を有効にする場合は、結果サイズと描画コストが増えるので、worker から戻る packet の arrival skew と stale rejection を別に測るのが安全です。欠損をゼロ扱いにせず、missing / late / below confidence を分けてログに残すと調整しやすくなります。

When wiring a real model, use the `detectForVideo(video, timestamp)` timestamp as the bundle ID and connect UI drawing, command routing, and analytics events through that ID. If optional face blendshapes or pose segmentation masks are enabled, result size and draw cost increase, so packet arrival skew and stale rejection should be measured separately. Missing outputs should not be treated as zeros; logging missing / late / below-confidence separately makes tuning easier.

If you try one thing

In the derivative sample, set dwell frames to 8 and cooldown to 10, then press Inject intent to see the boundary where commands are stabilized instead of firing immediately.
