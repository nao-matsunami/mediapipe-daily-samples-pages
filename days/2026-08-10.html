Image Embedder で自作キャンバス素材の近さを比較する

Compare generated canvas patches with Image Embedder-style similarity

MediaPipe Tasks Image Embedder の `embed()` と `ImageEmbedder.cosineSimilarity()` を意識した、自作の画像パッチ比較サンプルを追加しました。3枚のキャンバス素材をその場で生成し、fallback の軽量特徴量で即時比較しつつ、環境が許せば公式 MobileNetV3 small Image Embedder に切り替えて cosine similarity を確認できます。

注目事例と何が面白いか

Notable example and why it matters

今日の注目は Image Embedder を「写真検索の裏側」ではなく、UI 上で作った素材や画面状態の近さを評価する小さな道具として扱うことです。公式 Web guide は `FilesetResolver.forVisionTasks()` で WASM を解決し、MobileNetV3 small の model path を `ImageEmbedder.createFromOptions()` に渡して `embed(image)` を呼ぶ流れを示しています。今日の自作サンプルでは外部画像を並べず、キャンバスで生成した3つのパッチを比較対象にしました。

Today's notable angle is treating Image Embedder not as a hidden photo-search primitive, but as a small tool for judging the similarity of generated UI materials or visual states. The official Web guide shows resolving WASM with `FilesetResolver.forVisionTasks()`, passing the MobileNetV3 small model path to `ImageEmbedder.createFromOptions()`, then calling `embed(image)`. Today's original sample compares three generated canvas patches instead of listing external images.

表現・インタラクションのアイデア

Expression and interaction idea

Preset、Jitter、Rotation、Variant を動かすと、3枚の生成パッチが変わり、similarity matrix と best pair が即時更新されます。初期状態はローカル fallback の色グリッドとエッジ差分で動きます。Load MediaPipe が成功すると、同じキャンバスを公式 Image Embedder に渡し、`ImageEmbedder.cosineSimilarity()` の結果で matrix を更新します。

Changing Preset, Jitter, Rotation, and Variant regenerates the three patches and immediately updates the similarity matrix and best pair. The initial mode uses local fallback color-grid and edge-difference features. When Load MediaPipe succeeds, the same canvases are passed to the official Image Embedder and the matrix updates with `ImageEmbedder.cosineSimilarity()` results.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積できるデータは生成パラメータ、キャンバス画像、fallback 特徴量、MediaPipe embedding、pairwise similarity、best pair、runtime mode です。Image Classifier と組み合わせると「同じカテゴリ内で近い見た目」を抽出できます。Object Detector や Interactive Segmenter の ROI を切り出して Image Embedder に渡せば、画面内の部品や商品候補の近傍検索に発展します。Web Worker と IndexedDB を足すと、ブラウザ内の小さなビジュアル記憶にもできます。

The accumulated data includes generation parameters, canvas images, fallback features, MediaPipe embeddings, pairwise similarity, best pair, and runtime mode. Combined with Image Classifier, it can retrieve visually close items within the same category. Passing Object Detector or Interactive Segmenter ROIs into Image Embedder can grow into nearest-neighbor search for page components or product candidates. Adding a Web Worker and IndexedDB would turn it into a small in-browser visual memory.

制作に使えそうな技術メモ

Production note

実装では `@mediapipe/tasks-vision@0.10.22` を CDN import し、`FilesetResolver.forVisionTasks()`、`ImageEmbedder.createFromOptions()`、`runningMode: "IMAGE"`、hosted MobileNetV3 small model を使う経路を用意しました。公式 guide の注意通り `embed()` は同期的に返るため、今回は3枚だけに限定しています。動画や多数画像で試すなら worker に逃がし、`quantize` と `l2Normalize` の切り替えを UI に出すのが次の実装ポイントです。

The implementation prepares a CDN-import path for `@mediapipe/tasks-vision@0.10.22`, `FilesetResolver.forVisionTasks()`, `ImageEmbedder.createFromOptions()`, `runningMode: "IMAGE"`, and the hosted MobileNetV3 small model. As the official guide notes, `embed()` returns synchronously, so this sample limits itself to three images. For video or many images, the next implementation step is to move embedding into a worker and expose `quantize` and `l2Normalize` toggles.
