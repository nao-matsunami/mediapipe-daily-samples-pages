OpenCV.js で動きの差分マスクを観察する

Inspect motion difference masks with OpenCV.js

OpenCV.js の3本目として、現在フレームとゆっくり更新される背景モデルを比較し、`absdiff()`、`accumulateWeighted()`、threshold、motion mask、blob box、motion coverage を観察できる自作 HTML ラボを追加しました。

一覧代表サンプルを開く

今日の重要トピック

  1. `cv.absdiff()` は現在フレームと背景モデルの差分を取り、軽量な動き検出の入口になる。

    `cv.absdiff()` compares the current frame with a background model and provides a lightweight entry point for motion detection.

  2. `cv.accumulateWeighted()` を使うと背景を少しずつ更新でき、静止した変化を徐々に背景へ吸収できる。

    `cv.accumulateWeighted()` updates the background gradually, letting still changes settle into the model over time.

  3. 差分画像を threshold して motion mask に変換すると、`findContours()` で動いている領域を blob box として扱える。

    Thresholding the difference image creates a motion mask, and `findContours()` can turn moving regions into blob boxes.

  4. motion coverage と blob count は、Pose Landmarker の速度や Object Detector の box と組み合わせる補助信号になる。

    Motion coverage and blob count are useful helper signals for Pose Landmarker velocity or Object Detector boxes.

  5. OpenCV.js が使えない環境でも同じ UI を確認できるよう、Canvas の pixel array fallback を入れた。

    A Canvas pixel-array fallback keeps the same UI usable when OpenCV.js is unavailable.

注目事例と何が面白いか

Notable example and why it matters

今日の注目は、OpenCV.js の処理を単一フレームから時間方向の観察へ広げることです。edge と contour は画像内の構造を見ましたが、motion difference は前後の変化を見ます。背景モデルとの差分を取るだけでも、カメラ内の動き、画面内の注目領域、UI の発火候補を軽量に作れます。

Today's focus is extending OpenCV.js from single-frame inspection into time-based observation. Edges and contours inspect structure inside one image, while motion difference inspects change across frames. Comparing against a background model can cheaply produce movement regions, attention areas, and UI trigger candidates.

表現・インタラクションのアイデア

Expression and interaction idea

サンプルは Synthetic source を常に持ち、Start Camera で実カメラにも切り替えられます。Source、Diff、Mask、Boxes を切り替えながら、Difference threshold、Background learn、Minimum area、Max blobs を調整します。Reset BG を押すと背景モデルを次フレームで作り直せるため、動き検出の安定点を探しやすくしています。

The sample always has a synthetic source and can switch to a real camera with Start Camera. It exposes Source, Diff, Mask, and Boxes views, with controls for difference threshold, background learning rate, minimum area, and max blobs. Reset BG rebuilds the background on the next frame, making it easier to find a stable motion-detection point.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

このサンプルで得られる motion coverage、blob count、motion box、background learn 設定は、行動検出や視覚エフェクトの補助ログになります。Pose Landmarker と合わせれば体の動き量、Object Detector と合わせれば物体 box 内の変化、Image Segmenter と合わせれば人物領域内だけの motion mask を作れます。GLSL へ渡せば動いた領域からパーティクルや残像を出す入力になります。

The sample's motion coverage, blob count, motion boxes, and background-learning settings can become helper logs for action detection or visual effects. Combined with Pose Landmarker it can estimate body movement, with Object Detector it can inspect changes inside object boxes, and with Image Segmenter it can restrict motion masks to person regions. Sent to GLSL, moving regions can drive particles or trails.

制作に使えそうな技術メモ

Production note

OpenCV.js では Canvas から `cv.imread()` で現在フレームを読み、grayscale を `CV_32F` に変換して背景モデルと `cv.absdiff()` します。背景は `cv.accumulateWeighted()` で少しずつ更新し、差分を `cv.threshold()` して motion mask にします。mask は `cv.findContours()` と `cv.boundingRect()` で blob box へ変換し、`cv.countNonZero()` で coverage を計測します。

The OpenCV.js path reads the current frame from Canvas with `cv.imread()`, converts grayscale to `CV_32F`, and compares it with the background model using `cv.absdiff()`. The background updates gradually with `cv.accumulateWeighted()`, then the difference is thresholded into a motion mask. The mask is converted into blob boxes with `cv.findContours()` and `cv.boundingRect()`, while `cv.countNonZero()` measures coverage.

俯瞰メモ

Bird's-eye memo

OpenCV.js 側は edge、contour、motion の3種類になりました。edge は境界、contour は領域、motion は時間変化です。MediaPipe が意味ラベルやランドマークを返すのに対し、OpenCV.js は画像そのものの構造と変化を返します。この2系統を合わせると、入力理解と表現変換の足場がかなり広がります。

The OpenCV.js track now has edges, contours, and motion. Edges capture boundaries, contours capture regions, and motion captures temporal change. MediaPipe returns semantic labels and landmarks, while OpenCV.js returns image structure and change. Combining both tracks broadens the foundation for input understanding and expressive transformation.
