今日の重要トピック

  1. Face Landmarker は顔の 478 点 3D ランドマーク、表情 blendshape、顔変換行列を返せるため、単なる点描画から表情 UI や avatar 制御へ進めやすい。

    Face Landmarker can return 478 3D face landmarks, expression blendshapes, and facial transformation matrices, which makes it useful beyond drawing points.

  2. Web 版は `@mediapipe/tasks-vision` と `FilesetResolver.forVisionTasks()` で WASM を解決し、静止画では `detect()`、動画では `detectForVideo()` を使う。

    The Web version resolves WASM through `@mediapipe/tasks-vision` and `FilesetResolver.forVisionTasks()`, using `detect()` for images and `detectForVideo()` for video.

  3. 公式ガイドは `detect()` / `detectForVideo()` が同期実行で UI thread を塞ぐ点を明記しており、ライブ表情 mirror へ進めるなら Worker 化が重要になる。

    The official guide notes that `detect()` and `detectForVideo()` are synchronous and block the UI thread, so Worker execution matters for a live expression mirror.

  4. 公式 web demo と `mediapipe-samples-web` は対応タスクや設定 UI の確認に便利だが、今日の公開代表はこのワークスペース内の自作最小サンプルにした。

    The official web demo and `mediapipe-samples-web` help inspect task coverage and controls, but today's public representative is the original local sample.

  5. MediaPipe 本体の GitHub release では Web / WASM / Tasks 周辺の更新が続いているため、日次サンプルはバージョン固定と最新ウォッチを分けて進める。

    MediaPipe GitHub releases continue to change Web / WASM / Tasks internals, so this archive separates pinned sample versions from latest watch notes.

注目事例と何が面白いか

Notable example and why it matters

今日の注目は Face Landmarker の blendshape を、顔メッシュ表示の副産物ではなく UI の主役にすることです。公式ガイドでは顔ランドマーク、表情係数、顔変換行列を返せるタスクとして説明されており、フィルター、効果、virtual avatar の入口になります。今日のサンプルでは mouthOpen、mouthSmileLeft / Right、browInnerUp、eyeBlinkLeft / Right をバーとメーターに変換し、表情を数値の変化として見られるようにしました。

Today's focus is treating Face Landmarker blendshapes as the main UI rather than a side effect of face-mesh rendering. The official guide describes the task as returning face landmarks, expression coefficients, and facial transformation matrices, which can drive filters, effects, and virtual avatars. This sample turns mouthOpen, mouthSmileLeft / Right, browInnerUp, and eyeBlinkLeft / Right into bars and meters.

表現・インタラクションのアイデア

Expression and interaction idea

サンプルは Synthetic face、Load MediaPipe、Upload face image、Start camera、Freeze frame の入口を持ちます。合成顔では fallback のランドマークと blendshape を即表示し、MediaPipe が読み込める環境では画像やカメラ静止画に対して `detect(canvas)` を実行します。Mesh density で点の密度を変え、表情バーで数値変化を確認できるようにしました。

The sample exposes Synthetic face, Load MediaPipe, Upload face image, Start camera, and Freeze frame paths. The synthetic face immediately shows fallback landmarks and blendshapes, while environments that load MediaPipe run `detect(canvas)` on uploaded or frozen camera frames. Mesh density changes point density and expression bars show score changes.

制作に使えそうな技術メモ

Production note

実装では `@mediapipe/tasks-vision@0.10.22` から `FaceLandmarker` と `FilesetResolver` を import し、`face_landmarker.task` を `createFromOptions()` で読み込みます。`outputFaceBlendshapes` と `outputFacialTransformationMatrixes` を true にし、アップロード画像やカメラ静止画を Canvas に描いてから `detect(canvas)` に渡します。公式 API では `FilesetResolver.forVisionTasks()` が WASM file set を解決し、SIMD 対応も確認します。

The implementation imports `FaceLandmarker` and `FilesetResolver` from `@mediapipe/tasks-vision@0.10.22`, then loads `face_landmarker.task` through `createFromOptions()`. It enables `outputFaceBlendshapes` and `outputFacialTransformationMatrixes`, draws uploaded images or frozen camera frames to Canvas, and calls `detect(canvas)`. The official API resolves the WASM files and checks SIMD support through `FilesetResolver.forVisionTasks()`.
