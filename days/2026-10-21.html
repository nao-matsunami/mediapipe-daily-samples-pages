表現・インタラクションのアイデア

Expression and interaction idea

本命 `WASM Loading Progress Storyboard` は回線・モデルサイズ・端末係数で、WASM、モデル、compile、初回推論のバーを変えます。download は実測 bytes、後半は推定 time と表示します。派生 `Model Prefetch Consent Router` は Wi‑Fi / モバイル / Data Saver、空き領域、同意から先読み可否を変えます。

The main storyboard changes WASM, model, compile, and first-inference bars using network, model-size, and device inputs; downloads are labelled measured bytes and later stages estimated time. The derivative router changes prefetch policy from connection, storage, and consent.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

残すなら URL や生入力ではなく、asset 種別、開始・終了時刻、byte 数の bin、cancel 理由、cache hit、接続種別、同意状態だけに絞れます。Performance API、Storage API、Service Worker、AbortController、FilesetResolver、Web Worker と組み合わせれば、端末内で初期化の遅れと再試行を診断できます。

Retain only asset type, start/end, binned bytes, cancellation reason, cache hit, connection class, and consent state—not URLs or raw input. Performance API, Storage API, Service Worker, AbortController, FilesetResolver, and Web Worker can diagnose local startup delay and retry.

制作に使えそうな技術メモ

Production note

実装では fetch の ReadableStream がある区間だけ byte 進捗を実測として扱い、compile・GPU warm-up は ETA の幅を含む推定として明示します。取得には AbortController を渡し、画面遷移・Data Saver・同意撤回で止められるようにします。model asset は hash / version をキーにし、失敗した部分ダウンロードを成功扱いにしません。

Treat byte progress as measured only where fetch ReadableStream exists, and label compile/GPU warm-up as estimates with uncertainty. Pass AbortController to fetch and stop on navigation, Data Saver, or consent withdrawal. Key model assets by hash/version and never treat partial failed downloads as cache hits.

俯瞰メモ

Bird's-eye memo

Web ML の初回体験では、モデルそのものより「今何を待っているか」が不信感を左右します。工程を分け、推定には推定と書き、いつでも止められる設計は、速い回線だけを前提にしない実用的な表現です。

In first-run Web ML, trust is often shaped more by knowing what is being awaited than by the model itself. Stage separation, honest estimates, and cancellation make an experience that does not assume a fast network.
