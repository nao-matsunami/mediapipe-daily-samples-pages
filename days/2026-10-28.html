注目事例と何が面白いか

Notable example and why it matters

v1.1.0 prevents overlapping Web WASM embedding calls and adds stats logging. The main probe makes admission and stale rejection visible.

表現・インタラクションのアイデア

Expression and interaction idea

本命では乱れの確率と推論時間を動かし、単調増加するtimestampだけを緑で採用します。逆順バーストを注入すると赤い古い結果が捨てられます。派生は結果の年齢をLIVE/HOLD/OFFの色とレーダーに変換し、数値がもっともらしくても古ければ抑止する見せ方を試します。

The main admits only monotonic timestamps and makes reverse bursts red. The derivative turns result age into LIVE/HOLD/OFF radar language.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

映像を保存しなくても、入力timestamp、結果timestamp、result age、source size、ROI、mirror、generation、drop理由を記録すれば、Taskごとの遅延や画面の誤採用を比較できます。Pose/Hand/Face Landmarker、Performance API、Canvas/WebGL、同意済みのWeb Tasks統計、Web Audioの通知と組み合わせると、現場向けの鮮度監視へ発展します。

Persist timestamps, age, dimensions, ROI, mirroring, generation, and drop reason—not video—to compare latency and bad adoption across Tasks.

制作に使えそうな技術メモ

Production note

入力ごとに単調なtimestampを付け、結果を描く直前にgeneration一致・timestampの新しさ・年齢上限を判定します。callbackの到着順ではなく入力起点の時刻を基準にし、HOLD表示には年齢を併記します。source切替時はlast timestampとgenerationをリセットして、前セッションの結果を採用しません。

Attach monotonic input time, then check generation, novelty, and age just before drawing. Use input-origin time, tag HOLD with age, and reset session state on source changes.

俯瞰メモ

Bird's-eye memo

Web MLの不安定さはモデル精度だけの問題ではなく、非同期の時間設計でもあります。result ageをUIの正式な状態にすると、古い値を滑らかに見せる誘惑より、現在の映像に対して何を知っているかを正直に伝えられます。

Web ML instability is also temporal design. Formalizing result age lets the UI state honestly what it knows about the current scene.
