Language Detector で多言語メモを行単位で仕分ける

Gate multilingual notes line by line with Language Detector

MediaPipe Tasks Language Detector の `detect(text)` を意識した、自作の多言語メモ仕分けサンプルを追加しました。複数行のテキストを言語コードと確信度で判定し、対象ロケールに一致する行とレビューが必要な行を分けます。環境が許せば公式モデルを任意ロードし、失敗してもローカルの軽量ヒューリスティックで同じ UI を検証できます。

今日の重要トピック

  1. Language Detector Web guide は 2026-08-07 UTC 更新で、`@mediapipe/tasks-text`、text WASM、`LanguageDetector.createFromOptions()`、`detect(inputText)` の最小経路を示している。

    The Language Detector Web guide was updated on 2026-08-07 UTC and shows the minimal path through `@mediapipe/tasks-text`, text WASM, `LanguageDetector.createFromOptions()`, and `detect(inputText)`.

  2. Language Detector は string 入力を受け取り、ISO 639-1 / locale-like code と probability を含む予測リストを返す Text task。

    Language Detector is a Text task that accepts string input and returns predictions with ISO 639-1 / locale-like codes and probabilities.

  3. 推奨モデルは 315 KB の軽量モデルとして説明され、110 言語を識別できるため、ブラウザ内の多言語入力整理に向いている。

    The recommended model is described as a lightweight 315 KB model that can identify 110 languages, making it useful for in-browser multilingual input triage.

  4. 設定項目は `maxResults`、`scoreThreshold`、`categoryAllowlist`、`categoryDenylist` で、allowlist と denylist は同時利用不可。

    Configuration options include `maxResults`, `scoreThreshold`, `categoryAllowlist`, and `categoryDenylist`; allowlist and denylist are mutually exclusive.

  5. MediaPipe Tasks の privacy notice は入力処理がデバイス上で行われ入力データは Google サーバーへ送られない一方、API 利用メトリクスの扱いには同意設計が必要だと説明している。

    The MediaPipe Tasks privacy notice says input processing happens on device and input data is not sent to Google servers, while API metrics still require consent-aware product design.

Notable example and why it matters

今日の注目は、Language Detector を単なる言語表示ではなく、多言語メモや問い合わせ文を行単位で仕分ける小さな運用 UI として扱うことです。公式 Web guide は CDN から `@mediapipe/tasks-text` と text WASM を読み込み、`LanguageDetector.createFromOptions()` に `language_detector.tflite` を渡して `detect(inputText)` を呼ぶ流れを示しています。今日のサンプルは複数行テキストを入力にし、対象ロケール、確信度しきい値、レビュー判定をまとめて確認できます。

Today's notable angle is treating Language Detector not just as a language label, but as a small operations UI for triaging multilingual notes or support messages line by line. The official Web guide shows loading `@mediapipe/tasks-text` and text WASM from a CDN, passing `language_detector.tflite` into `LanguageDetector.createFromOptions()`, then calling `detect(inputText)`. Today's sample takes multi-line text and lets you inspect target locale, confidence threshold, and review decisions together.

表現・インタラクションのアイデア

Expression and interaction idea

Product Notes、Support Queue、Travel Memo のプリセットを切り替え、対象ロケールとレビューしきい値を動かすと、各行が target / review に即時分類されます。Load MediaPipe を押すと公式モデル経路を試し、読み込みに成功した場合は各行に `detect(text)` を適用します。失敗時もローカル fallback が同じ結果形を返すため、UI、しきい値、カード構造、公開アーカイブの体験を途切れさせません。

Switch Product Notes, Support Queue, and Travel Memo presets, then adjust the target locale and review threshold to classify each line as target or review. Pressing Load MediaPipe tries the official model path and applies `detect(text)` to each line when loading succeeds. If it fails, the local fallback returns the same result shape, preserving the UI, threshold behavior, card structure, and public archive experience.

サンプルデータの可能性と組み合わせ

Possibilities unlocked by sample data and combinations

蓄積できるデータは入力行、推定言語コード、確信度、対象ロケール、しきい値、target / review 判定、検出元です。Text Embedder と組み合わせると、言語ごとに分けた後で近い問い合わせやリリースノートをまとめられます。Text Classifier と合わせれば、言語判定後に sentiment / topic を付けるレビューキューになります。Vision / Audio サンプルのログを短文化して渡せば、各ログの言語別整理や翻訳前処理にも使えます。

The accumulated data includes input line, predicted language code, confidence, target locale, threshold, target / review decision, and detection source. Combined with Text Embedder, it can group similar support messages or release notes after splitting by language. With Text Classifier it becomes a review queue that adds sentiment / topic after language detection. If Vision / Audio sample logs are converted into short text, this can organize logs by language or prepare them for translation.

制作に使えそうな技術メモ

Production note

MediaPipe 経路は `@mediapipe/tasks-text@0.10.22` を ESM import し、`FilesetResolver.forTextTasks()` で WASM を解決し、`LanguageDetector.createFromOptions()` に hosted model を指定します。公式ドキュメントの設定項目は `maxResults`、`scoreThreshold`、`categoryAllowlist`、`categoryDenylist` なので、次回は UI 側に allow / deny list を加えると公式オプションに近づきます。今回の fallback は文字種と少数の機能語だけを見る簡易版で、公式モデルの代替ではなく UI 検証用です。

The MediaPipe path imports `@mediapipe/tasks-text@0.10.22` as ESM, resolves WASM with `FilesetResolver.forTextTasks()`, and points `LanguageDetector.createFromOptions()` at the hosted model. The official configuration options are `maxResults`, `scoreThreshold`, `categoryAllowlist`, and `categoryDenylist`, so adding allow / deny list UI next would align the sample more closely with the official options. The fallback only checks scripts and a few function words; it is for UI validation, not a replacement for the official model.

The selected prototype is `Language Detector Locale Gate`. Next additions should include allowlist / denylist matching the official options, Text Embedder nearest-neighbor search within each language, Text Classifier issue labeling, and queue saving before translation.
