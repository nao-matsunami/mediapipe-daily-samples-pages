Reference implementation notes

  • 公式サンプルは Image Segmenter を Worker に置き、mask bitmap を postMessage transfer してから結果マスクを close しています。
  • confidence mask を WebGL/Canvas に描画する場合、再利用する still image は canvas 化して再アップロードを減らす設計が有効です。
  • このサンプルは外部デモの埋め込みではなく、ローカルでマスク寿命を理解するための最小検証 UI です。
