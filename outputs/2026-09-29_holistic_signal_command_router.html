Holistic Signal Command Router

Holistic Landmarker の pose / face / hand 信号を、アプリ内コマンドへ変換する派生試作です。顔の集中度、肩の傾き、両手の距離、左右手の信頼度を合成し、誤発火を抑える dwell と cooldown を動かします。

Command policy

Holistic の出力は情報量が多いため、そのまま UI action にせず、姿勢、表情、手の距離を小さな intent に分けてから dwell と cooldown で安定化します。
