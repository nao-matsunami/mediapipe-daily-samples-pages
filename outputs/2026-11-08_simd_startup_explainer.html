SIMD Startup
Explainer

MediaPipe Tasks Web SDK v1.2.2 では非 SIMD WebAssembly build が除去されました。この派生試作は、能力検出の結果を「読めないエラー」ではなく、試せる次の行動へ変換する起動画面の模型です。実SDKは読み込みません。

環境を切替

ボタンで仮想ブラウザの能力を変えます。結果は「モデルを読み込む」「説明して別の経路へ」の二択を明示します。

選択された起動ルートSIMD WASM を準備Web Taskを読み込み、モデル取得へ進みます。
