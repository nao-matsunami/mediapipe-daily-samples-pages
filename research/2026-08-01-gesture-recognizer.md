# 2026-08-01 Gesture Recognizer research

- Google AI Edge Gesture recognition guide for Web: Gesture Recognizer recognizes hand gestures in real time and outputs gestures, handedness, image landmarks, and world landmarks. Source: https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer/web_js
- Gesture Recognizer overview: the task can invoke application features based on recognized gestures and supports score thresholding plus label allowlist/denylist. Source: https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer
- JS API reference: `GestureRecognizer.createFromOptions()`, `recognize()`, `recognizeForVideo()`, `setOptions()`, and `HAND_CONNECTIONS` are the main web API surface. Source: https://developers.google.com/edge/api/mediapipe/js/tasks-vision.gesturerecognizer
- Official samples: `google-ai-edge/mediapipe-samples-web` includes a Gesture Recognizer sample and public web demo. Keep those as references, while the public archive card should be the original local sample. Sources: https://google-ai-edge.github.io/mediapipe-samples-web/ and https://github.com/google-ai-edge/mediapipe-samples-web
