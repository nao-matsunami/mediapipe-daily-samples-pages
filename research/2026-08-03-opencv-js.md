# 2026-08-03 OpenCV.js note

## Focus

OpenCV.js を MediaPipe daily の外側に置く最初の追加技術として確認する。狙いは、カメラや合成画像を入力にして、grayscale、blur、threshold、Canny edge を同じ UI で触れる最小ワークベンチを作ること。

## Useful primitives

- `cv.imread(canvas)` and `cv.imshow(canvas, mat)` let a sample move between Canvas and OpenCV Mats.
- `cv.cvtColor()` gives a clear first step from RGBA camera frames to grayscale processing.
- `cv.GaussianBlur()` is useful before thresholding and edge detection because it makes noisy frames easier to reason about.
- `cv.threshold()` creates a binary mask that can later be compared with MediaPipe segmentation masks.
- `cv.Canny()` gives an edge map that pairs naturally with contours, line detection, and shader overlays.
- Mats must be deleted after use in an animation loop to avoid leaking WASM heap memory.

## Sample idea

`OpenCV Edge Threshold Lab` keeps a deterministic synthetic image available by default, then allows a live camera source on localhost. Controls expose blur radius, binary threshold, Canny low and high thresholds, and overlay gain. Metrics show edge density, white pixel coverage, and frame cost.
