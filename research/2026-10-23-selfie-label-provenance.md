# 2026-10-23 research

- MediaPipe v1.1.1 is the released baseline; it refreshes WASM/SPM assets and updates JavaScript Retrieval SDK snippets.
- MediaPipe v1.1.0 added Web Tasks landmark presence scores and Web retrieval APIs, while its release notes also emphasize avoiding overlapping WASM embedding calls.
- Public PR #6341 proposes `selfieMode` for Web vision landmark tasks and PR #6340 proposes ObjectDetector labels. Both are watch items only, not released API guarantees.
- The official Web samples page remains a useful task-category reference; this archive continues to publish only original, local samples as cards.
